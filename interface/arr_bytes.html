public interface arr_bytes

Byte footprint of an allocatable array (0 when unallocated), so a gated-off slot naturally contributes nothing to a counted total. The COUNTED companion to the runtime’s MEASURED free-memory delta: each *_state_t sums its own arrays through this, the driver reports the total before enter_data (works on CPU builds too, where there is no device query), and mem_log_device_actuals reconciles the count against the measured mapping — a state array added without a matching bytes() term makes the measured map exceed the count and self-announces the drift (the anti-rot guard for the otherwise rot-prone per-slot count).
