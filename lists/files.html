rki_kernel_fused_ml.F90

Fused per-cell post-update kernels for the multilayer structured solver. Collapse the per-stage post-flux kernel chain (update → distribute → bottom friction → truncate → barotropic momentum → wind/pressure/precip → coriolis) into one launch per stage; no horizontal neighbour reads except the atmospheric pressure gradient. Caller must run tracer advection BEFORE these kernels (CWC needs OLD h_layer).
rki_kernel_fused_unstr.F90

Fused update kernels for the unstructured solver: merge save + update + friction + wind + protect into one kernel launch per RK stage, keeping state in registers across the sequence. Entry points: fused_update_stage1_unstr — save U^n + Euler + friction + protect fused_update_stage2_unstr — Euler + friction + protect + RK2 avg + protect
