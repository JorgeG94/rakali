Cell-centric unstructured mesh, flat 1D layout.

Stores per-cell geometry (centroid, area, CFL radius) and per-edge-of-cell quantities (length, outward normal, midpoint, neighbour cell, neighbour-side edge index, boundary group). Edges are implicit: every triangle has exactly three edges, indexed locally as i in 1..3. Edge i is the edge opposite local vertex i.

Per-edge-of-cell arrays use shape (3, ncells_total) so the three edges of cell k are contiguous in memory and the cell index is the slow-varying (column-major) axis – the natural Fortran layout for a do concurrent (k = 1:ncells_owned) hot loop.

All cells are owned (ncells_owned == ncells_total). Geometry is built once at init and never modified during the run.

real(kind=wp), private, parameter :: SI_MAX_DEV_ANGLE_DEG = 5.0_wp

Fail-loud ceiling on the max circumcentre-line deviation angle for the semi-implicit TPFA operator. A clean Delaunay mesh measures < 1e-2 deg (edge orthogonal to the circumcentre line by construction); anything above 5 deg means a non-Delaunay / corrupted triangulation that TPFA would solve inconsistently — abort at configure rather than silently return a subtly-wrong eta.

public subroutine mesh_unstr_si_quality_gate(mesh, ok)

Fail-loud mesh-quality gate for the semi-implicit TPFA operator (Casulli & Walters 2000 orthogonal-centre requirement, made explicit). Aborts via ok=.false. (the caller error-stops) when either * the max circumcentre-line deviation angle exceeds SI_MAX_DEV_ANGLE_DEG (a non-Delaunay / corrupted mesh), or * the smallest interior edge_delta is non-positive (an obtuse triangle put its circumcentre outside itself => a flipped / zero transmissibility K_e = Hf*len/delta). A clean Delaunay mesh (meshpy/pymetis pipeline) passes trivially.

private subroutine build_surrogate_neighbours(mesh)

Surrogate neighbours: same as neighbours but the cell itself stands in for boundary edges. Lets the gradient kernel index neighbour values without branching on -1. Filled for every cell – halo cells included – so that any kernel that happens to dereference surrogate_neighbours(:, k) for a halo k still gets a valid index.

private subroutine compute_geometry(mesh)

Compute per-cell area, centroid, CFL radius, and per-edge length, outward normal, and midpoint for every cell – owned AND halo. Halo cells need real geometry too because the reconstruction kernel reads neighbour centroids when computing edge values across partition edges. Edge i is opposite local vertex i; in CCW orientation that gives an outward normal.

private subroutine compute_si_geometry(mesh)

Fill the semi-implicit TPFA edge geometry: the circumcentre-to- circumcentre distance edge_delta and the edge/centre-line deviation angle edge_dev_angle for every edge of every cell, plus the mesh-wide quality-gate scalars max_dev_angle / min_edge_delta over the OWNED interior edges. Runs after build_neighbours so neighbour circumcentres are available. Host-only (init-time; the device never re-derives geometry).
