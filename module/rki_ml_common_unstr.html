integer, public, parameter :: BPG_NZ_MAX = 20

Per-column stack-workspace bound for the unstructured multilayer kernels (BPG, vertical exchange, vertical viscosity, KPP, k-eps, tracer advection). Fixed size so the compiler can emit fixed-size thread-local storage on GPU. DISTINCT from the structured/ocean NZ_STACK_MAX in rki_constants: the unstructured path is thread-per-cell with many such locals per kernel frame, so this bound stays deliberately small — raising it multiplies the per-thread local memory of every unstructured column kernel. Build-configurable via -DRAKALI_BPG_NZ_MAX=<n> (CMake cache variable, plumbed as the 20 preprocessor define; default 20).

The requirement is BPG_NZ_MAX >= nz + 1 — see bpg_nz_required below for the derivation and the survey of every consumer. Enforced fail-loud by validate_config.

public pure function bpg_nz_is_sufficient(nz) result(ok)

.true. when the COMPILED BPG_NZ_MAX covers nz layers on the unstructured multilayer path. Callers that get .false. must refuse the run: exceeding the bound is NOT a crash — the unstructured BPG kernels silently return (no baroclinic pressure gradient at all) and the unguarded column kernels silently overrun thread-local storage.
