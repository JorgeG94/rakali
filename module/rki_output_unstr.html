Writes solution snapshots to CF UGRID 1.0 NetCDF files.

Topology (nodes, face-node connectivity, centroids, areas) is written once at file creation. Time-varying fields (stage, xmom, ymom) are appended as 2D slices (face, time) on each snapshot. Bathymetry is written once as a static 1D field (face).

One file with ncells_owned faces. The cell_global_id variable is the cell index 1..ncells_owned.

Two init paths: * output_unstr_init — takes mesh_unstr_t + unstr_state_t. * output_unstr_init_from_arrays — takes raw arrays.

Two write paths: * output_unstr_write_snapshot — reads from unstr_state_t. * output_unstr_write_snapshot_from_arrays — takes raw arrays.

Per-tracer variables come from the registry — one NetCDF variable per state%multilayer%tracers(:) entry, metadata pulled directly from each unstr_tracer_t. Adding a sediment / passive scalar produces a correctly- labelled output variable with no I/O changes.
