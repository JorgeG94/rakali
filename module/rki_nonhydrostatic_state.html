Per-layer NH prognostics (u_layer, v_layer, w, q_nh) + RK2 saves, CG Poisson workspaces, barotropic pre-HLL momentum saves, mode-splitting time-average + barotropic-tendency arrays, and the NH/CG/split scalar config. Lives at state%nh; allocated by state_init only when use_nonhydrostatic = .true. (else scalar defaults). Mode-splitting arrays further gated on split_ratio /= 1.

private subroutine nh_state_init(this, grid)

Allocate all NH arrays at the grid size and the configured layer count. Mode-splitting arrays are allocated only when split_ratio /= 1. PCG preconditioner workspace cg_z is always allocated; the OpenACC enter data directive is conditional on nh_preconditioner so unused PCG state isn’t mapped to the device.
