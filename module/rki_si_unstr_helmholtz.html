The elliptic (wave-continuity) machinery for the semi-implicit free-surface mode on the UNSTRUCTURED (triangular) backend — the two-point flux (TPFA, Casulli & Walters 2000) scheme. Substituting the semi-implicit edge momentum into depth-integrated continuity gives a Helmholtz system for eta^{n+1} at the circumcentres:

[ M - gtheta^2dt^2 * div_c( Hf grad_e ) ] eta^{n+1} = RHS

with the CELL-CENTRED FV divergence (÷area_c, depth units) and the per-edge TPFA transmissibility K_e = Hf_e * len_e / delta_e (delta_e = circumcentre-to-circumcentre distance). M is the cell mass coefficient (1 on the all-wet 2D path; the wet/dry Newton diagonal in P3.3).

THE LOAD-BEARING DETAIL: the operator (T eta)_c = -(coef/area_c) * sum_e sign_e K_e (eta_nbr - eta_c) is self-adjoint in the AREA-WEIGHTED inner product = sum_c area_c x_c y_c, NOT the plain dot — variable cell areas scale the rows. Every CG/Jacobi reduction here carries the area weight; uniform area recovers the structured harness. Get it wrong and CG stalls (prototype §7.5).

CELL-CENTRIC DOUBLE-VISIT: every apply computes each cell’s own row from its own 3 edges (reads neighbour eta, writes own Ap) — the house flux pattern, GPU-race-free. Interior edges are visited twice (once from each side); no scatter, no atomics. Single-rank, owned-cell loops.

public pure function si_unstr_edge_flux(hf, eta_c, eta_nbr, inv_delta) result(flux)

The single discrete edge-normal transport used by the TPFA operator’s div(Hf grad eta), the edge predictor’s explicit PGF, and the edge back-substitution: flux = Hf * (eta_nbr - eta_c) / delta (along the outward normal) Sharing ONE flux function across the operator/back-sub is what makes the back-substituted edge transports satisfy discrete continuity identically (mass consistency). !$acc routine seq for device do-concurrent bodies.

private pure function si_unstr_face_depth_linear(h_c, h_nbr) result(hf)

All-wet (2D barotropic) edge effective depth: the arithmetic mean of the two cells’ still-water depths, Hf = 0.5*(h_c + h_nbr). This is the gated-mean rule (face_depth_wetdry) in its all-wet limit — it reduces EXACTLY to the linear edge depth. Wall edges never call this (Hf stays 0); Dirichlet edges pass the ghost h.

public subroutine si_unstr_cg_solve(mesh, ncell_total, ncell_owned, eta, cg_r, cg_p, cg_Ap, cg_z, eta_diag, Hf_edge, g_theta2_dt2, precond, rtol, iter_out, mass_res_out, mass_diag, mg)

Area-weighted (optionally preconditioned) CG for the TPFA Helmholtz eta-solve, warm-started from eta^n. On entry cg_r holds the RHS and eta the warm start. EVERY dot product carries the mesh%area weight (the operator is self-adjoint in _A only — prototype §7.5); the convergence gate is the area-weighted relative residual ||r||_A^2 < rtol^2 ||rhs||_A^2 on the UNPRECONDITIONED residual in every mode (comparable iteration counts). Preconditioners: NONE (plain), JACOBI (z = eta_diag*r), MG (aggregation-multigrid V-cycle via mg, z = Vcycle_Ahat(area*r) — the same area*r symmetric-space RHS the Jacobi apply implicitly uses).

public pure subroutine si_unstr_compute_diag(mesh, ncell_total, ncell_owned, Hf_edge, eta_diag, g_theta2_dt2, mass_diag)

Precompute the reciprocal of the TPFA Helmholtz operator diagonal (Jacobi preconditioner): diag_c = M_c + (gtheta^2dt^2/area_c) * sum_{e in c} K_e stored as 1/diag. M_c = 1 (linear) or a+floor (wet/dry, present mass_diag). Wall edges (Hf=0) drop out => diag -> M there.

public subroutine si_unstr_compute_rhs(mesh, ncell_total, ncell_owned, eta_n, u_star, u_n, rhs, dt, theta, Hf_edge, eta_ghost_edge, g_theta2_dt2)

Assemble the theta-blend RHS from the CELL edge transports: RHS_c = eta^n_c - (dt/area_c) * sum_{e in c} sign_e * [thetaU_e + (1-theta)U^n_e] * len_e + (coef/area_c) * sum_{Dirichlet e in c} K_e * eta_ghost_e U_e / U^n_e are per-edge transports (double-visit (3,ncell)); the blend flux telescopes over interior edges (each shared by 2 cells with opposite outward normals) and every wall edge carries 0 (Hf=0 kills the predictor PGF, and U^n is zeroed on dead edges), so total mass is conserved to CG tolerance + round-off by construction. The Dirichlet term is the coefficient-space route: the operator (si_unstr_apply_helmholtz) treats the fixed ghost eta as 0, so its real value is carried here.

public pure subroutine si_unstr_face_depths(mesh, ncell_total, ncell_owned, n_bc, height, bed, bc_type, bc_eta_ext, Hf_edge, eta_ghost_edge)

Build the per-edge frozen effective depth Hf_e (2D all-wet path) AND the per-edge Dirichlet ghost surface eta_ghost_edge: interior/partition edge: Hf = 0.5(h_c + h_nbr); ghost unused (0). WALL edge: Hf = 0 (no coupling — no-flux Neumann in the coeffs). TIDAL/CLAMPED (Dirichlet) edge: the ghost surface is the prescribed eta_bc; the ghost bed mirrors the cell bed so the ghost depth is h_ghost = eta_bc - b_c, and Hf = 0.5(h_c + h_ghost). The ghost eta is stashed in eta_ghost_edge(i,k) for the operator + RHS + back-sub (the coefficient-space Dirichlet route).

private subroutine si_unstr_precond_apply(mesh, ncell_total, ncell_owned, r, z, eta_diag, use_mg, mg)

Preconditioner apply z = M^{-1} r for the area-weighted PCG. JACOBI: z = eta_diag*r (diagonal). MG: one aggregation-multigrid V-cycle of the symmetric Ahat on the area-weighted RHS (agglom_unstr_vcycle_precond folds the area*r), which reduces to the Jacobi apply when the V-cycle is a single diagonal sweep — the generalisation is exact (module header). Owned cells only; the ghost band of z is left as the caller set it (pre-zeroed).
