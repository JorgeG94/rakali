real(kind=wp), public, parameter :: DESING_EPS = H_VANISHED

Kurganov & Petrova (2007) desingularization depth eps (m) for the 2D barotropic update/protect kernels AND the CFL timestep estimator: the velocity u = sqrt(2) h hu / sqrt(h^4 + max(h^4, eps^4)) equals hu/h exactly for h >= eps and rolls off quadratically below, and momentum is reconstructed as hu := h*u. Momentum in cells thinner than eps is smoothly suppressed, NOT zeroed — the pre-2026-08 hard zero below THIN_LAYER_THRESHOLD (together with FROUDE_CAP = 10, see FROUDE_BACKSTOP) froze thin water at wet/dry fronts: Ritter dry-bed tip at 1.49 c0 instead of 2 c0, beach films that never drained. One value shared by the update kernels and the dt estimator, so both agree about what “thin” means. (Earlier the estimator alone used eps = max(1e-3, 0.01*min(dx,dy)); the grid term is gone — on coarse grids it made the estimator blind to real velocities in cells shallower than 1% of the cell width, a latent CFL bug.)

Value: tied to H_VANISHED — the codebase’s established “dynamically vanished” depth below which a column has no meaningful velocity. Measured dose-response on the Ritter dry-bed tip (dx = 0.25 m, exact celerity 2 c0, no-clamp ceiling 1.888 c0 at this resolution; design sweep at FROUDE_BACKSTOP=100): eps = 1e-3 -> 1.617 c0 eps = 1.5e-4 -> ~1.73 c0 (this value; 1.736 in the final backstop=50 configuration) eps = 3e-5 -> 1.776 c0 Diminishing returns below H_VANISHED, and the front position at a RESOLVABLE depth (1 cm) is best at 1.5e-4 (lag 0.36 m of 62.6 m travelled, 0.6%).
real(kind=wp), public, parameter :: DRY_TOLERANCE = 1.0e-6_wp

real(kind=wp), public, parameter :: FROUDE_BACKSTOP = 50.0_wp

Last-resort Froude bound at wet/dry fronts: momentum is rescaled so |u| <= FROUDE_BACKSTOPsqrt(gh). This is a blowup ARRESTER, not physics shaping — it replaced FROUDE_CAP = 10 (2026-08), which bound exactly where the physics lives: the exact Ritter dry-bed tongue has Fr = 2(sqrt(h_l/h) - 1), unbounded at the tip, and the leading wet cell measured at exactly Fr = 10 (tip celerity 1.49 c0 instead of 2 c0). A Fr-shaped cap that binds a draining film also freezes it structurally: saturated cells obey hu = Frsqrt(g)h^1.5, so a uniform film has zero flux divergence and dh/dt = 0 (measured: ~40 consecutive beach cells all at u = -10*sqrt(g h), shoreline pinned).

Why it exists at all: without it, a thin draining film on a sloping bed develops a genuine velocity runaway ABOVE the desingularization depth, where KP07 is an identity — measured u -> 4e3 m/s at h ~ 3.5e-3 m and a ~2000x CFL dt collapse on the Carrier-Greenspan beach fixture.

Why 50 (all measured at DESING_EPS = 1.5e-4, dx = 0.25 m; the 200 row is from the design sweep, where it matched 100 exactly): backstop = 50 -> Ritter tip 1.736 c0, beach max|u| ~10.6 m/s backstop = 100 -> Ritter tip 1.744 c0, beach max|u| ~17.8 m/s backstop = 200 -> Ritter tip = the 100 value, max|u| ~31.5 m/s The dry-front tongue is insensitive to the value (the KP07 desingularization governs it), but the Carrier-Greenspan runup DISCRIMINATES: at backstop 100 the freed runup jet overshoots and strands a cm-scale wedge on the beach through rundown (excursion at a 1 cm detector 11.8 m vs exact 20 m); at 50 the excursion is 18.9 m (5.6% of exact) with the rundown edge at x = 83.9 m vs the exact 80 m. 50 is also the lowest measured value that leaves the Ritter tongue unchanged; going much lower re-approaches the measured cap-10 film-freeze pathology (Fr-shaped caps bind at drainage velocities once Fr*sqrt(g h) ~ a few m/s at cm depths). NaN safety: the rescale triggers only on a TRUE comparison, so a NaN speed passes through un-“corrected” and fails loudly instead of being laundered into a plausible extreme value (see CLAUDE.md on NaN-blind clamps).

integer, public, parameter :: NZ_STACK_MAX = 128

Maximum vertical layers for per-column stack workspace inside do concurrent. Stack arrays in the BPG, remap, kappa-shear, Redi and diag-remap kernels are dimensioned by this constant so the compiler can emit fixed-size thread-local storage on GPU.

The requirement is NZ_STACK_MAX >= nz + 1 — see nz_stack_required below for the derivation and the survey of every consumer. Enforced fail-loud by validate_config.

History: 100 -> 256 (2026-06-19), on the belief that the Redi neutral-diffusion sweep needed 2*nz+2 of this constant. It does not: Redi’s nsurf locals are declared 2*NZ_STACK_MAX+2 (rki_ocean_redi.F90 PoLc/PoRc/KoLc/KoRc/hEc), so they scale with the constant and only need NZ_STACK_MAX >= nz. Lowered 256 -> 128 (2026-08-05) after that measurement: 256 was ~2x larger than any consumer needed and cost ~4 GB of CUDA per-thread local memory, which the driver reserves at each kernel’s first launch and never returns. 128 covers the largest shipped case (nz=90, acc_channel_kitchensink_xl.nml) and the largest test (nz=100) with headroom.

Heap-allocated workspace arrays (PPM snapshots, remap snapshots) have no such limit — they are allocated at runtime.

Ignore SSH when forming target_h; layer thicknesses follow the static H · dsig(k) decomposition. integer, public, parameter :: VCOORD_HYCOM = 9

Hybrid z/isopycnal coordinate (P3, Bleck 2002 / MOM6 coord_hycom). Runs the exact VCOORD_RHO density-space inversion (same ocean_vcoord_compute_target_h_rho kernel, hybrid=.true.) but adds two HYCOM deltas around it: a bottom-up density monotonize before the inversion, and a z nominal-floor sweep after it that pushes too-shallow interfaces down to a fixed-resolution surface band (dsig·(H+η)). Net effect: a fixed-res near-surface z* band (no surface collapse) with an isopycnal interior — the production GVC coordinate. Reuses rho_target / rho_ref_pressure; no new knobs.
integer, public, parameter :: VCOORD_LAGRANGIAN = -1

Pure Lagrangian / isopycnal — h_layer evolves freely and is never remapped. compute_target_h returns the current h unchanged and the ALE remap step is a no-op. Distinct from VCOORD_EULERIAN_Z (which targets the static H · dsig decomposition): LAGRANGIAN tracks material surfaces, so for adiabatic flow it reproduces MOM6’s COORD_CONFIG="gprime" NK=2 isopycnal layering. Parsed from “lagrangian” / “isopycnal”.
integer, public, parameter :: VCOORD_RHO = 8

Isopycnal coordinate (P2). Layer interfaces are placed on prescribed potential-density surfaces rho_target(0:nz) (monotone-increasing, referenced to rho_ref_pressure). The ALE regrid inverts a PPM reconstruction of the column density profile for the depth where ρ equals each interior target, then remaps T/S/tracers/velocities onto the new grid. Bottom-up convention: rho_target(0) (lightest) anchors the surface interface (k=nz); rho_target(nz) (densest) the bed (k=1). Validation-grade alone (weakly-stratified columns collapse); HYCOM hybrid is the production follow-on (P3). See rki_ocean_vcoord :: ocean_vcoord_compute_target_h_rho_impl.

integer, public, parameter :: VCOORD_Z_FIXED = 7

Fixed-z interfaces with vanishing layers in shallow water. ALE remap pulls h_layer(k) → h_target(k) where the targets come from absolute-depth interfaces z_target = (0, h_nominal, 2·h_nominal, ..., h_ref) with h_nominal = h_ref/nz_ml. In deep cells the interfaces stay locked at those depths; in shallow cells the bed-side layers vanish to a minimum thickness h_min while the surface layer absorbs the residual. Mirrors MOM6’s COORD_CONFIG = "gprime" layer structure and the existing seed_h_layer_z_fixed_impl IC algorithm — used as a per-step ALE target rather than an init-only seed so the interface stays anchored as the simulation evolves.
