Reads solution (h, hu, hv) from a parent domain NetCDF output file and fills ghost cells on BC_NESTED edges using Flather radiation with spatially-varying external values. Parent file: dims (x, y, time), variables h/hu/hv(x,y,time) + coordinate variables. Interpolation is linear along each edge in space and between bracketing snapshots in time.
