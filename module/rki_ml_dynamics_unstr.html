Continuity-side machinery: layer initialisation from the barotropic state, distribute / distribute-with-remap (sigma + zsigma ALE), barotropic recompute from layer momenta, save / RK2-average for layer fields, diagnostic vertical velocity, vertical exchange of momentum.

Layer index convention: k = 1 is the BOTTOM sigma layer, k = nz_ml is the TOP / surface layer. w_interface is indexed 1..nz+1 with w_interface(1) = 0 at the bed and w_interface(nz+1) at the free surface.

public pure subroutine ml_compute_barotropic_momentum_unstr(state)

Depth-integrate layer momentum back onto the barotropic fields: HU = sum_k hu_k, HV = sum_k hv_k. Also refreshes height_cv = sum_k h_k and stage_cv from the updated height so the 2D barotropic state stays in sync with the layers. Called between RK stages and at the end of the step after the layer RK2 average.

public pure subroutine ml_distribute_barotropic_unstr(state)

Distribute the barotropic HLL acceleration across layers (sigma): du = (hu_new - hu_pre)/H_new; u_k_old = hu_k_old/h_k_old; h_k = dsig_kH_new; hu_k = h_k(u_k_old + du) so the acceleration lands uniformly while preserving shear. Requires xmom_pre/ymom_pre from ml_save_barotropic_pre_unstr.

public subroutine ml_distribute_with_remap_full_unstr(state)

VCOORD_ZSTAR_FULL variant of ml_distribute_with_remap_unstr (momentum + thickness only). Builds the per-cell target dz_new via vcoord_target_dz_column_zstar_full from the cell’s local vcoord_z_ref_col(:, cell) slice. Per-tracer remap is done by ml_remap_tracer_unstr (looped over the registry by the solver), which is vcoord-agnostic — it reads the new h_layer this routine writes. Shares the remap_dz_old workspace with the sigma path.

public subroutine ml_distribute_with_remap_unstr(state)

Barotropic-to-layer distribution with vcoord reshaping for non-sigma coords (z-sigma hybrid, zstar-lite) — momentum + thickness only: 1. Save old thicknesses into remap_dz_old (read by ml_remap_tracer_unstr for the per-tracer remap). 2. Compute new target thicknesses via vcoord, write h_layer. 3. Distribute the barotropic acceleration to the new layers. Per-tracer remap is done by ml_remap_tracer_unstr (looped over the registry by the solver); touches only top-level allocatables so no outer shim needed.

public subroutine ml_init_layers_unstr(state)

Fill the per-layer arrays from the barotropic state. Pure sigma: h_k = dsig_kH, hu_k = dsig_kHU, hv_k = dsig_k*HV. For zsigma / hybrid coords vcoord_target_dz_column lays out the per-column thicknesses (matching distribute_with_remap), so the first step’s tracer RK2 average stays geometrically coherent.

public subroutine ml_remap_tracer_unstr(state, hTr_layer)

Conservatively remap ONE tracer from the saved pre-update layer thicknesses (state%multilayer%remap_dz_old, written by the distribute-with-remap routines) onto the current h_layer (the new vcoord target). Vcoord-agnostic: shared by the sigma / zsigma / zstar-lite and the ZSTAR_FULL paths, since both write the new target into h_layer before this runs. Split out of the fused remap so the solver can loop it over the whole tracer registry; the per-tracer arithmetic is exactly what the fused impls used for S/T (scale dz_old to sum to H_new, depth-weighted column-mean fallback at vanishing layers, conservative remap_column), so salinity / temperature results are unchanged.
