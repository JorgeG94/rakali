Holds the Shu-Osher coefficient table for the selectable explicit time integrator (time_scheme). Every scheme is built from the same forward-Euler stage primitive: stage i advances the running iterate by beta(i)*dt, then blends with the start-of-step state U^n:

E       = U^(i-1) + beta(i)*dt * L(U^(i-1))     ! Euler step
U^(i)   = alpha(i)*U^n + (1 - alpha(i))*E       ! convex blend

All four schemes are strong-stability-preserving (SSP) so the per-stage convex structure keeps the wetting/drying positivity of forward Euler. ssp_coeff is the factor by which the stable timestep exceeds the forward-Euler CFL limit (1 for euler/rk2/rk3, 2 for rk43).

Data, not polymorphism: a concrete container + an enum, mirroring the vcoord_type / EOS-variant / use_hllc dispatch idiom. The type is host-side orchestration only (its weights reach kernels as scalars by value) so it is never device-mapped.
