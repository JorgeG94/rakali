Manages the conserved variables, bathymetry, and flux arrays

All arrays use SoA layout with dimensions (nx_total, ny_total) where nx_total = nx_physical + 2*nghost. The first index (i / x-direction) is the fast-varying index for coalesced GPU memory access.

private pure function state_bytes(this) result(nbytes)

Counted allocatable footprint of the whole coastal state, summed from each sub-slot’s own bytes() (each 0 when its feature is gated off, so the total tracks conditional allocation directly). Reported before enter_data and reconciled against the measured device mapping — see rki_mem_report.
