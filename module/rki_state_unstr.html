Composition wrapper around the unstructured solver state. Mirrors the structured state_t decomposition: this type is a thin shell that owns mode flags + timing + BC config + the four slope-limiter knobs, and composes the sub-state objects:

state%barotropic – depth-integrated CV + edge reconstruction + RK2 saves + Chapman state + per-edge mass flux + barotropic physics scalars. state%multilayer – per-layer dynamics + tracer registry + vcoord + workspaces + EOS / mixing / BPG scalar config.

The mesh metadata stays as a separate mesh_unstr_t argument threaded through the kernels (not embedded on state) – same convention as before the split.

Variable conventions: stage = w = h + b (free-surface elevation) xmom = uh (x-momentum) ymom = vh (y-momentum) bed = b (bathymetry, static after init) height = h (= stage - bed, recomputed each step)

All centroid arrays are sized to mesh%ncells_total so halo cells are available to the kernels without special-casing.

public subroutine state_unstr_enable_si(state, mesh, precond, rtol, dt_fixed, ok, wetdry, n_sub, bsub_fill)

Enable the semi-implicit (Casulli) free-surface mode on this state: run the fail-loud TPFA mesh-quality gate, allocate the si slot (with the P3.2 multilayer column slots when use_multilayer, AND/OR the P3.3 Casulli wet/dry slots when wetdry — the two slot groups gate independently, so 3D + wet/dry coexist), and stash the CG controls. Call AFTER state_unstr_init (so the multilayer sub-state exists and nz_ml is known) and BEFORE state_unstr_enter_data. ok=.false. (gate failure or a bad precond having already error-stopped) leaves use_semi_implicit off so the caller can abort cleanly.
