The SCHISM-inspired (Casulli 1990; Casulli & Cattani 1994; Zhang & Baptista 2008) per-column algebra of the 3D semi-implicit multilayer step, ported per-cell to the (nz, ncells) axis layout (k FIRST, cell LAST — the unstructured convention, OPPOSITE of the structured (nx,ny,nz)), plus the edge-wise recovery / tracer kernels that replace the structured face kernels:

  1. si_unstr_build_nu_interface — PP81 Richardson interface viscosity.
  2. si_unstr_column_solve — plain-u^n predictor responses G_k/R_k (face/edge-based PGF split: the predictor carries NO surface PGF), Thomas factorisation, three-RHS back-solve, Hhat/Gbar integrals. Bottom drag: Manning quadratic on the bed row (the unstructured barotropic state carries no linear-drag knob — Manning-only, documented deviation from the structured use_linear_drag option).
  3. si_unstr_fill_predictor_edges — the theta-blend RHS edge predictor U*_e from the face-averaged Gbar (vector projected on the outward edge-normal) minus the explicit (1-theta) surface PGF.
  4. si_unstr_recover_edge_layers — post-CG per-layer EDGE transport recovery; column sums telescope EXACTLY to the 2D back-substituted edge transport (the mass-consistency invariant). Dirichlet boundary edges use the structured mouth-consistency seeds inline: ghost G = 0, ghost R = -1, ghost h_k = dsig_k*max(eta_bc - b_c, 0).
  5. si_unstr_fill_mass_flux_edges — the blended column edge flux the eta update used (drives the dsig tracer split + next step’s U^n).
  6. si_unstr_advect_tracer_dsig — depth-proportional, race-free, first-order-upwind tracer advection: per-layer edge flux EXACTLY dsig_k * mass_flux_e (the only split consistent with the dsig-slaved thickness update => uniform tracers invariant per layer); upwind values read from the PRE-STEP snapshot only. FLAT-IMPL: called per registry tracer through the outer shim in the step module (the array-of-derived-types device rule).
  7. si_unstr_edge_layers_to_cells — per-layer least-squares A-grid cell-momentum reconstruction (the 2D reconstruction, per layer).
  8. si_unstr_update_thickness_ml — h^{n+1} = eta^{n+1} - b and the sigma slaving h_k = dsig_k*h.
  9. si_unstr_apply_wind_top_layer — dt*tau/rho on the surface layer (k = nz) transport; the uniform-scalar unstructured wind.

Layer convention (load-bearing): BOTTOM-UP — k=1 bed, k=nz surface. Cell-centric double-visit throughout (each cell owns its 3 edge values; interior edges computed twice, bit-exactly antisymmetric — no scatter, no atomics). Explicit-shape dummies in every DC kernel (NVHPC descriptor-walk rule); fixed-size local columns NZ_STACK_MAX.

public pure subroutine si_unstr_apply_wind_top_layer(nz, nct, nco, h_layer, hu_layer, hv_layer, wind_tau_x, wind_tau_y, dt)

Surface wind stress into the TOP layer (k = nz) transport: dt*tau/RHO_WATER — the explicit forcing that rides the pure-u^n predictor into G_k (by linearity R_k / Hhat / the Helmholtz operator are untouched; zero wind => bit-identical). The unstructured wind is the uniform scalar pair on the barotropic state (wind_tau_x/y), so this is a trivially cheap kernel. Gated on a wet surface layer.

public pure subroutine si_unstr_build_nu_interface(nz, nzp1, nct, nco, h_layer, hu_layer, hv_layer, rho_layer, rho_0, nu_max, nu_bg, ri_alpha, nu_iface)

PP81 Richardson-number interface viscosity, per cell (mirror of the structured si_build_nu_interface, (nz, ncells) order): nu_iface(1, c) = 0 (bed interface) nu_iface(k+1, c) = nu between layers k and k+1 nu_iface(nz+1, c) = 0 (surface interface) Ri = g(drho/rho_0)h_avg / |du|^2 (floored at 0); nu = nu_max/(1 + ri_alpha*Ri)^2 + nu_bg; vanished layers decouple.

public pure subroutine si_unstr_column_solve(nz, nzp1, nct, nco, h_layer, hu_layer, hv_layer, nu_iface, manning_n, dt, g_col_u, g_col_v, r_col, Hhat_cell, Gbar_cell_x, Gbar_cell_y)

Per-column semi-implicit solve — the structured si_column_solve ported per-cell ((nz, ncells) order). Predictor: PLAIN old-time velocity u^n_k = hu_k/max(h_k, H_VANISHED) — NO surface PGF (the edge-based PGF split: by linearity of the tridiagonal, all surface PGF applies at edges via the -1 response R_k). Bottom drag: Manning quadratic on the bed row (the unstructured barotropic state carries no linear-drag knob): cf = gn^2 / H_total^{1/3}; lambda = cf|u_bed| / h_1 folded into the bed diagonal as +dt*lambda. Tridiagonal, Thomas factorisation, three back-solves (u^n, v^n, -1), then Gbar = sum_k h_k G_k, Hhat = -sum_k h_k R_k (>= 0). R_k is axis-independent (u and v share the matrix).
