Horizontal advection (PPM and first-order upwind), vertical exchange and diffusion, distribution under the barotropic step, horizontal Laplacian diffusion, surface fluxes, RK2 plumbing, ghost-cell boundary application, and bounds clamping.

Both prognostic tracers (salinity hS, temperature hT) share these generic kernels — callers pick which array to pass.

The advection / PPM / horizontal-diffusion kernels are pure: the per-kernel scratch (PPM reconstruction snapshots, Jacobi neighbour snapshots) is caller-owned through tracer_scratch_t, allocated once up front by the solver (tracer_scratch_ensure) and released by tracer_scratch_destroy. Writing an intent(out) scratch dummy is pure-legal, so the kernels keep purity while still avoiding the per-step allocate/deallocate that would stall the GPU pipeline.

type, public ::  tracer_scratch_t

Persistent per-kernel scratch owned by the caller (the solver, or a unit test). Allocated once up front to (nx,ny,nz), device- attached, and reused for every kernel call so the pure kernels never allocate. Each group is guarded by a want_* flag in tracer_scratch_ensure, so a PPM-only run does not allocate the upwind snapshot and vice-versa.

private pure function edge_prescribes(edge_type) result(prescribes)

An edge accepts a prescribed inflow tracer value when it is an inflow (BC_INFLOW) or a Dirichlet-eta OPEN edge (BC_TIDAL / BC_CLAMPED) — the edges through which water can enter the domain carrying a specified concentration. The prescription still only takes effect when tr_inflow >= 0 (checked at the call site), and the prescribed ghost is only READ on inflow (upwind), so a reversing tidal edge is inflow-value on flood and zero-gradient on ebb.

public pure subroutine ml_init_tracer_stratified(h_layer, hTr_layer, tr_bottom, tr_surface, grid, nz)

Seed a tracer with a linear vertical profile: tr_bottom at k=1 (bed) to tr_surface at k=nz (surface), per the bottom-up layer convention. The profile is computed inline from the two scalars (no host-side per-layer array) so the seed runs correctly on the device after enter_data. Caller guarantees nz > 1. Mirrors the unstructured ml_init_tracer_stratified_unstr. hTr_k = h_layer_k * [tr_bottom + dtr*(k - 1)]

public pure subroutine ml_seed_tracer(h_layer, hTr_layer, tr_uniform, tr_bottom, tr_surface, grid, nz)

Seed one tracer’s hTr field, dispatching between the uniform and the linear-stratified profile from the tracer’s IC scalars. When both tr_bottom and tr_surface are set (non-zero) and nz > 1 a linear profile is laid down from tr_bottom at the bed (k=1) to tr_surface at the surface (k=nz); otherwise every layer is filled with tr_uniform. This is the single stratified-vs-uniform gate shared by all IC seed sites (rki_init, rki_api), so the polarity convention lives in exactly one place. Mirrors ml_seed_tracer_unstr.

public pure subroutine ml_settling_tracer(h_layer, hTr_layer, bed, w_s, grid, nz, dt)

Constant-velocity downward settling of one tracer (e.g. suspended sediment), conservative + positivity-preserving. Bottom-up convention: k=1 is the bed layer, k=nz the surface. The whole suspended profile sinks at w_s; whatever crosses the bed deposits into the 2D bed reservoir, so total sum_k hTr + bed is conserved.

Allocate (or resize) the caller-owned tracer-kernel scratch and attach it to the GPU. Idempotent: a no-op once each requested group exists at the requested size; resizes if (nx,ny,nz) changes (e.g. a unit test re-running at a different grid size).
