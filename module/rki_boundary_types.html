public subroutine bc_init_chapman(bc, h, b, nx_total, ny_total, nghost)

Allocate Chapman eta_old arrays for all four edges (so they are available for unconditional GPU mapping in solver_enter_data) and seed the active edges from current eta. Inactive edges keep their zero source value – the kernel never reads them when the corresponding bc%<side> is not BC_CHAPMAN, so the zeros are harmless.
