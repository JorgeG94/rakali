Subroutines
dump_flux_io

Diagnostic snapshot of the barotropic state arrays as they sit between the flux call and the update call inside an RK stage.

Reads the existing state%barotropic%{h, hu, hv, b, flux_*, mass_flux_*} arrays that the solver has already populated on device — does not re-run the kernel. The dump must be inserted between solver_compute_barotropic_flux and compute_update so that (h, hu, hv, b) are still the flux kernel’s inputs and flux_* / mass_flux_* are the matching outputs. After compute_update, h/hu/hv are overwritten.

Input fields are written over the full ghost-padded array shape (nx_total, ny_total); outputs are written over the interior (nx_phys, ny_phys). Combined with the nghost global attribute, that lets a reader reconstruct the 9-point cross stencil (i-2..i+2, j) + (i, j-2..j+2) that each interior cell consumes.

public subroutine dump_flux_io(filename, state)

Public only for the unit-test suite (no production module imports it); ignore when developing production code in other modules. Snapshot the flux-kernel inputs and outputs from state to a NetCDF file at filename.
