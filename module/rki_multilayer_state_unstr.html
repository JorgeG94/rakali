Per-layer prognostic arrays ((nz_ml, ncells_total) axis order — layer index fastest, matching column-stencil kernels), vcoord definition + GPU mirror, diagnostic vertical velocity, EOS density + reference profile, tracer registry, per-step Jacobi/gradient workspaces, and the scalar physics parameters the kernels read.

Lives at state%multilayer. Allocated by state_unstr_init when nz_ml is passed. Mirrors structured multilayer_state_t with the cell-centric axis order swapped.

private subroutine unstr_multilayer_register_passive_tracer(this, mesh, name, tr_init, tr_min, tr_max, kappa_bg, hdiff_kappa)

Append a passive tracer (eos_coeff = 0) to the registry. Must be called AFTER init and BEFORE state_unstr_enter_data (so the new tracer’s hTr gets device-mapped) — enforced via registry_locked: once the registry is device-mapped the call logs an error and returns without touching it. S/T keep their indices.
