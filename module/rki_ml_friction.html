ml_apply_bottom_friction ml_apply_coriolis

Manning quadratic bottom friction on the bottom layer (k=1) and per-layer Coriolis rotation of every layer’s momentum (ml_apply_coriolis).

Per-layer (vs depth-averaged) friction/Coriolis damps and rotates the baroclinic shear (gravity currents, dense overflows) using each layer’s own velocity. Replaces the depth-averaged apply_coriolis on the multilayer path; the barotropic-only path keeps the depth-averaged version.

Layers are bottom-up (k=1 bed, k=nz surface): bed friction acts at k=1. Semi-implicit friction: hu_new = hu_old / (1 + dtC_d|u_b|/h_k), C_d = g*n^2/H^{1/3}.

public pure subroutine ml_apply_bottom_friction(h_layer, hu_layer, hv_layer, manning_n, use_linear_drag, drag_r, grid, nz, dt)

Apply bottom friction to the lowest active layer (k=1, bottom-up) using that layer’s velocity. Two semi-implicit drag laws: quadratic Manning (default): hu_new = hu / (1 + dtC_d|u_b|/h_k), C_d = gn^2/H^{1/3}, H = total column depth. linear Rayleigh (use_linear_drag): hu_new = hu / (1 + dtr).

public pure subroutine ml_apply_coriolis(h_layer, hu_layer, hv_layer, grid, nz, dt, f)

Per-layer Coriolis rotation: rotate every layer’s (hu_k, hv_k) through angle f*dt via the closed-form (energy-conserving, det=1) rotation matrix hu_new = hu_oldcos(fdt) + hv_oldsin(fdt) hv_new = -hu_oldsin(fdt) + hv_oldcos(fdt) f is a scalar (latitude-only). Skips layers below the dry-cell threshold so already-zeroed momentum is untouched.
