public subroutine accumulate_boundary_mass_out(state, stage_weight)

Accumulate the net volume that left the domain this RK stage into state%barotropic%mass_out. By the divergence theorem the boundary outflux equals -Σ_interior flux_h·area (interior face fluxes telescope), and flux_h is the SAME continuity tendency the update consumes (h += dt·flux_h), so with the matching RK stage weight this closes the mass budget to round-off — the console Error then measures only genuine non-conservation (e.g. dry-cell clamps).

Arguments

Type IntentOptional Attributes Name
type(state_t), intent(inout) :: state
real(kind=wp), intent(in) :: stage_weight

Stage contribution to the step’s h update (0.5 for each SSP-RK2 stage: h^{n+1} = h^n + 0.5·dt·(flux_h^1 + flux_h^2)).

private subroutine accumulate_sponge_mass_src(state, stage_weight)

Accumulate the net volume change caused by the sponge h-relaxation this RK stage into state%barotropic%mass_src. The sponge applies Δh = −dt·α·(h − h_ref), which can add or remove mass; this routine measures the actual h-change by summing h over interior cells before and after apply_sponge. No-op when no sponge edge is configured.
