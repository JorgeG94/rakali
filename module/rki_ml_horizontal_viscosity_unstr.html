public pure subroutine ml_horizontal_viscosity_smag_unstr(state, mesh, dt)

Smagorinsky (1963) horizontal viscosity for layer momentum on triangles. Velocity gradients via Green-Gauss; nu_h = (Cs^2A)|S|, stability-limited; FVM Laplacian. Jacobi snapshot on hu/hv for CPU/GPU consistency.
