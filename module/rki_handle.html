Magic-number sentinels. Distinct values per backend so a structured handle passed to an unstructured entrypoint (or vice versa) is rejected with the same code path as a fully bogus pointer. The values are arbitrary; they just need to be unlikely to occur in uninitialised memory and distinct from each other.
