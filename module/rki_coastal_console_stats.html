The coastal analogue of rki_ocean_console_stats: reduce the coastal state’s conservation + stability scalars (total mass, kinetic energy, max advective CFL, and — when multilayer — volume-mean salinity / temperature) and emit them through the SHARED rki_console_stats formatter, so the coastal console block looks identical to the ocean’s.

Reductions run on device (only the scalars cross the bus) and follow the interior-cell + NaN/dry guard pattern of compute_total_mass. Mass + layer sums reuse the existing rki_init helpers; KE and CFL add their own reductions here. Exposed for analytical unit tests (test_console_stats).
