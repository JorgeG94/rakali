Aggregation (agglomeration) multigrid V(2,2)-cycle preconditioner for the TRIANGLE semi-implicit free-surface Helmholtz system — geometric MG has no triangle hierarchy, so we coarsen the CELL GRAPH by greedy pairwise aggregation instead. The design is numpy-prototype-validated (local_archive/prototypes/q12_agglom_mg, STRONG GO: plain-CG plateau of thousands -> tens of MG-PCG iters).

WHAT IT PRECONDITIONS. The Fortran CG (si_unstr_cg_solve) runs the AREA-WEIGHTED PCG on the operator A (si_unstr_apply_helmholtz), inner product <x,y>_area = sum_c area_c x_c y_c. This module works in the genuinely-SYMMETRIC space Ahat = diag(area)*A (SPD M-matrix): Ahat[c,c] = area_c + coefsum_e K_e (coef = gtheta^2dt^2) Ahat[c,nbr] = -coefK_e , K_e = Hf_e*len_e/delta_e The Jacobi preconditioner the code already ships is, in this space, exactly z = Ahat_diag^{-1} (area*r); the MG apply is the direct generalisation z = Vcycle_Ahat(area*r) — one V(2,2) cycle from a zero guess (SPD + linear => a valid CG preconditioner). Passing area*r (not r) into the symmetric V-cycle is what makes it consistent with the area-weighted outer PCG (prototype driver §Ahat).

HIERARCHY. Cell graph coarsened ~2x/level by greedy pairwise aggregation (strongest-transmissibility partner). Built ONCE at init (static mesh). Every level’s operator is stored in a COMPACT variable-valence edge form nbr(mv,nc) / ke(mv,nc) / diag(nc); a coarse level’s operator is the GALERKIN P^T Ahat P with a 0/1 piecewise-constant P — which for aggregation equals a rediscretized agglomerate-TPFA (coarse mass = sum member areas, coarse transmissibility = sum of fine transmissibilities across the cut) EXACTLY, so the coarse STENCIL DOES NOT GROW (prototype: Galerkin == rediscretized to round-off). Transfers are P (inject) / R = P^T (sum-gather) — exact transpose by construction, no scaling factor.

REFRESH. Only the transmissibilities ke + diagonals depend on the per-step frozen Hf (coef is fixed). The STRUCTURE (aggregates, coarse adjacency, member lists) is static; ke/diag/dinv are rebuilt ONCE PER STEP on the HOST (fine level from the mesh geometry + current Hf, coarse levels by the Galerkin cascade) and pushed to the device — the same host-side per-step operator refresh the structured MG uses. NOT per V-cycle.

GPU. Each level owns explicit-shape device arrays + enter/exit_data. The level loop runs on the HOST; every device kernel (apply / damped- Jacobi smooth / residual / restrict / prolong) is called with FLAT EXPLICIT-SHAPE arguments — the level array is NEVER dereferenced inside a do concurrent (the array-of-derived-types device-indirection gotcha). Kernels are cell-centric (each cell writes only its own row / entry; restriction sums a coarse cell’s own members) — no neighbour scatter, no atomics. Damped Jacobi ping-pongs (read old, write new) — race-free. Single-rank v1 (no per-cycle halo).

integer, public, parameter :: AGGLOM_COARSE_SWEEPS = 40

Coarsest-level Jacobi sweeps (approximate solve from zero). FIXED (not convergence-gated) on purpose: a fixed sweep count makes the whole V-cycle a FIXED LINEAR SPD operator, which the outer STANDARD (non- flexible) area-weighted PCG requires — a residual-gated coarse solve would vary the sweep count with the RHS, making M RHS-dependent (flexible preconditioning) and breaking the constant-M PCG assumption. EFFICIENCY CAVEAT: for a very stiff Helmholtz (large SI dt) 40 sweeps can under-resolve the ~<=150-cell coarse system and lift the outer PCG count on larger/stiffer meshes; the funnel CI case is well inside the budget. Robustify (if ever needed) by raising this constant, not by gating — keep the operator fixed + linear.

public subroutine agglom_hierarchy_unstr_build(this, mesh, nco)

Build the level stack for nco owned cells. Only the mesh GEOMETRY is needed: the aggregation strength is the geometric transmissibility len/delta (a uniform-Hf, coef=1 proxy). Greedy pairwise aggregation picks the MAX-strength neighbour, which is invariant to a uniform positive scale, so the live per-step coef*Hf (folded in at refresh) never changes the STRUCTURE — the hierarchy is static. Host-only (runs before enter_data); the diag/ke are placeholders here and are overwritten by the first refresh before any solve.

private subroutine level1_operator(mesh, nco, coef, Hf_edge, lev, strength)

Fill level 1’s ke/diag/dinv from the mesh geometry + the per-edge frozen Hf (still-water synthetic at build, the live Hf_edge at refresh). Mirrors si_unstr_compute_diag + the interior off-diagonals of si_unstr_apply_helmholtz, so the symmetric Ahat row is exact: diag(k) = area_k + coef*sum_{Hf>0} K_e (interior + Dirichlet) off-diag ke to interior neighbours only. A Dirichlet boundary edge carries Hf>0 with no CG-unknown neighbour => it lands on the diagonal (ghost = homogeneous 0 in the error operator). Wall edges carry Hf=0 => dropped. strength returns |ke| per interior edge for aggregation. HOST; caller pushes to the device.
