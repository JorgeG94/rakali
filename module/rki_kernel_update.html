Advances the conserved variables: forward Euler update (each RK stage) and the SSP-RK2 averaging step.

Thin-cell treatment (all three kernels, in order): 1. negative depths are clamped to zero (momentum zeroed); 2. genuinely dry cells (h < DRY_TOLERANCE) have momentum zeroed; 3. thin-but-wet cells (h < eps = DESING_EPS) get the Kurganov & Petrova (2007) desingularized velocity u = sqrt(2) h hu / sqrt(h^4 + max(h^4, eps^4)) with momentum reconstructed as hu := h*u. For h >= eps the formula is the identity u = hu/h, so well-resolved cells are left bit-exact; 4. a last-resort Froude backstop |u| <= FROUDE_BACKSTOP*sqrt(g h) arrests the thin-film velocity runaway that develops at wet/dry fronts on sloping beds (measured: u -> 4e3 m/s at h ~ 3.5 mm and a ~2000x dt collapse without it). It is far above any depth ratio this scheme can resolve, so it never shapes the physics — see the constant’s docstring for the measurements.

eps is the same DESING_EPS used by compute_timestep, so the update and the CFL estimator agree about what “thin” means.

public pure subroutine compute_rk2_average(h, hu, hv, h0, hu0, hv0, grid)

SSP-RK2 averaging step: U^{n+1} = 0.5(U^n + U*), averaging the original state (h0, hu0, hv0) with the twice-advanced (h, hu, hv).

public pure subroutine compute_ssp_combine(h, hu, hv, h0, hu0, hv0, a_n, grid)

Generalized SSP Shu-Osher combine: U = a_nU^n + (1 - a_n)U, where U is the post-Euler-stage iterate and (h0,hu0,hv0) = U^n. Reduces exactly to compute_rk2_average for a_n = 0.5. Applies the same positivity + thin-cell treatment so each stage stays wet/dry-safe.

public pure subroutine compute_update(h, hu, hv, flux_h, flux_hu, flux_hv, grid, dt)

Forward Euler update U = U + dt*RHS (each SSP-RK2 stage). Also enforces non-negative depth, zeroes momentum in dry cells, and desingularizes thin-cell velocity (KP07) with a Froude backstop.
