Q1 (SI vertical-mixing closures) for the unstructured backend. The SI column solve consumes ANY interface viscosity through state%si%nu_iface; closures are pure FILLS of that slot. This module holds the flat explicit-shape fill kernels on the (nz, ncells) layout:

  • si_unstr_fill_nu_iface_from_keps — copy the k-epsilon keps_nut (interface-shaped (nz+1, n), advanced by the UNCHANGED ml_keps_update_unstr at SI cadence — the explicit kernel is already backward-Euler/Patankar) into nu_iface, with the SI convention’s bed/surface zero rows and the vanished-layer decoupling gate.
  • si_unstr_keps_copy_iface — interface-array copy for the optional keps_si_picard > 1 save/restore of the pre-step k / eps.
  • si_unstr_build_nu_interface_kpp — PP81 interior viscosity with the KPP (LMD94) shape-function overlay MAX’d in, written to nu_iface for the IMPLICIT column tridiagonal. NO explicit-flux CFL clamp — the coastal explicit ml_kpp_viscosity_unstr clamp would strangle the overlay at SI step sizes (dt = 120-480 s); the implicit solve is unconditionally stable at any nu.
  • si_unstr_kpp_diffusion_tracers — S/T IMPLICIT (Thomas) vertical diffusion with the PP81-cubic + KPP-overlay diffusivity, plus the LMD94 non-local counter-gradient transport applied after the diffusion (the coastal explicit order: vdiff-then-nonlocal), reading the post-diffusion surface salinity for F_S. Conserves column tracer content (no-flux tridiagonal, conservative nonlocal divergence).

Layer convention (load-bearing): BOTTOM-UP — k=1 bed, k=nz surface; interface m sits BELOW layer m (m=1 bed, m=nz+1 surface). Cell-centric do concurrent over cells; per-column serial work in-body with NZ_STACK_MAX locals; explicit-shape dummies throughout (NVHPC rule).

public pure subroutine si_unstr_build_nu_interface_kpp(nz, nzp1, nct, nco, h_layer, hu_layer, hv_layer, rho_layer, rho_0, nu_max, nu_bg, ri_alpha, u_star, buoy_flux, bl_depth, nu_iface)

PP81 interior interface viscosity with the KPP (LMD94) surface- boundary-layer overlay MAX’d in, for the SI implicit column solve: nu = max( nu_max/(1+ri_alphaRi)^2 + nu_bg, h_b * w_s * G(sigma) ) for interfaces inside h_b with G(sigma) = sigma(1-sigma)^2, sigma = d_iface/h_b, and the velocity scale w_s = sqrt(u_^2 + w_^2), w_^3 = max(0,-B_0)*h_b. NO dt clamp: the consumer is the unconditionally-stable implicit tridiagonal. Where the overlay is inactive (w_s = 0 / below the BL) the result is EXACTLY the PP81 si_unstr_build_nu_interface value.

public pure subroutine si_unstr_fill_nu_iface_from_keps(nz, nzp1, nct, nco, h_layer, keps_nut, nu_iface)

Copy the k-epsilon interface viscosity into the SI column-solve slot. keps_nut and nu_iface share the interface convention (m=1 bed, m=nz+1 surface); interior interfaces copy 1:1; bed and surface rows are forced to 0 (no flux through bed/surface — wind and drag enter the column solve separately), and an interface bounded by a vanished layer decouples (nu = 0), mirroring si_unstr_build_nu_interface so the closure swap changes ONLY the viscosity values.

public pure subroutine si_unstr_kpp_diffusion_tracers(nz, nzp1, nct, nco, h_layer, hu_layer, hv_layer, hS_layer, hT_layer, rho_layer, rho_0, nu_max, kappa_S_bg, kappa_T_bg, ri_alpha, cs_nonlocal, heat_flux, evap_minus_precip, cp, u_star, buoy_flux, bl_depth, dt)

S/T vertical diffusion with the KPP overlay for the SI step: IMPLICIT (Thomas) column solve with the PP81-CUBIC interior diffusivity + the KPP shape-function overlay MAX’d in (same overlay as momentum; no dt clamp — implicit), then the LMD94 non-local counter-gradient transport applied as a conservative interface divergence AFTER the diffusion (the coastal explicit order: vdiff-then-nonlocal), reading the post-diffusion surface salinity for F_S. gamma = 0 at bed and surface => the divergence conserves the column integral exactly. Conserves column tracer content (no-flux tridiagonal).
