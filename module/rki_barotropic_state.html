Depth-integrated conserved variables, bathymetry, flux-divergence and per-face mass-flux scratch, RK2 save buffers, and the scalar physics params the barotropic kernels read (Manning n, Coriolis f). Lives at state%barotropic; multilayer code reads h, hu, hv and mass_flux_x/y from here (produced by the barotropic step, consumed by layer-distribute + CWC tracer advection).

Cumulative net volume that has left the domain through its boundaries since t=0 (m³, positive = outflow), accumulated per RK stage from the scheme’s own flux divergence so the console conservation Error closes to round-off even with open BCs. See rki_console_stats / the driver’s budget wiring.
logical, public :: mass_out_tracked = .false.

Set .true. once the solver has accumulated mass_out. Covered paths: 2D-barotropic SSP-RK2 fused path + coastal multilayer nz>1. Not set by: nz=1 ML fused fast path (safe raw-drift fallback — see solver note), semi-implicit, generic-RK.
real(kind=wp), public :: mass_src = 0.0_wp

Cumulative volume ADDED to the domain by surface sources since t=0 (m³, positive = added), accumulated per RK stage from precipitation (h += dt·P), the evaporative mass sink (evap_mass_sink=.true.; negative contribution), and the sponge h-relaxation Δh. Feeds budget%mass_src in rki_console_stats so the residual (total−ref) + out − src stays ~round-off on forced runs instead of growing monotonically with the forcing.
logical, public :: mass_src_tracked = .false.

Set .true. once the solver has accumulated mass_src for the current run. Same coverage as mass_out_tracked: 2D-barotropic fused path + coastal multilayer nz>1. The closed budget (budget%mass_active) is enabled in the console only when BOTH flags are set.
logical, public :: use_hllc = .false.

Use HLLC (with contact wave for transverse momentum) instead of HLL for the barotropic Riemann flux. Structured-only — the unstructured solver always uses KNP central-upwind, which resolves contact discontinuities natively. Default .false..
logical, public :: use_linear_bottom_drag = .false.

Use linear (Rayleigh) bottom drag instead of quadratic Manning.
logical, public :: wind_surface_layer = .false.

Apply wind stress to the top layer (surface-concentrated) instead of the depth-uniform barotropic mode. Multilayer only.
