KPP surface-boundary-layer mixing for the coastal A-grid. Unlike the ocean path (implicit Thomas solve), the coastal path has no implicit vertical-diffusion solver, so the KPP overlay is fused with the explicit CFL-clamped diffusive-flux apply: * ml_kpp_boundary_layer — per column u_*, surface buoyancy flux B_0, and bulk-Ri boundary-layer depth h_b (LMD94 eq-23 V_t^2 term); bl_depth persists across steps to seed V_t^2 (self-bootstrapping). * ml_kpp_viscosity — momentum: nu_t = max(PP81 interior, KPP overlay h_b·w_s·G(sigma)), explicit flux to hu/hv. * ml_kpp_diffusion_tracers — S+T: same overlay + non-local counter-gradient transport under destabilizing forcing.

Overlay inactive (w_s=0) ⇒ falls through to bit-identical PP81. vmix_use_kpp off (default) leaves all results unchanged. Bottom-up layers (k=1 bed, k=nz surface); interface “k” sits between layer k and k+1.

public pure subroutine ml_kpp_boundary_layer(h_layer, hu_layer, hv_layer, rho_layer, hS_layer, rho_0, alpha_T, beta_S, cp, wind_x, wind_y, heat_flux, evap_minus_precip, ri_crit, c_vt2, u_star, buoy_flux, bl_depth, grid, nz)

Pass 1: per-column u_, B_0, and bulk-Ri boundary-layer depth h_b. u_ = sqrt(|tau|/rho_0), tau = surface wind stress (Pa). B_0 = g·(alpha_T·F_T - beta_S·F_S), kinematic fluxes F_T = Q_heat/(rho_0·cp), F_S = (E-P)·S_top; B_0 < 0 destabilizing. h_b : top-down bulk-Ri sweep; crossing of ri_crit interpolated. V_t²(d) = (c_vt2/ri_crit)·d·N(d)·w_s uses lagged bl_depth (zero on first call ⇒ self-bootstrapping). No crossing ⇒ h_b = H.

public pure subroutine ml_kpp_diffusion_tracers(h_layer, hu_layer, hv_layer, hS_layer, hT_layer, rho_layer, rho_0, nu_max, kappa_S_bg, kappa_T_bg, ri_alpha, cs_nonlocal, heat_flux, evap_minus_precip, cp, u_star, buoy_flux, bl_depth, grid, nz, dt)

Pass 2 (tracers): PP81 cubic interior diffusivity with the KPP overlay max’d in (same overlay as momentum), explicit flux on salinity + temperature, plus the non-local counter-gradient transport under destabilizing forcing. Fuses the two ml_vertical_diffusion_tracer calls; bit-identical to them where the overlay + non-local terms vanish.

public pure subroutine ml_kpp_viscosity(h_layer, hu_layer, hv_layer, rho_layer, rho_0, nu_max, nu_bg, ri_alpha, u_star, buoy_flux, bl_depth, grid, nz, dt)

Pass 2 (momentum): PP81 interior viscosity with the KPP shape-function overlay max’d in, then the explicit CFL-clamped diffusive flux applied to hu/hv. Identical to ml_vertical_viscosity everywhere the overlay is inactive (w_s = 0 or interface below the BL).
