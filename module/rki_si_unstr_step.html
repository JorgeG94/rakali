One semi-implicit (Casulli) step for the 2D barotropic free surface on the UNSTRUCTURED (triangular) backend — the TPFA / edge-transport scheme. INTERNALLY STAGGERED: the predictor / back-sub transports live on EDGES (per-cell double-visit u_edge(3,ncell), transport along each edge’s outward normal), matching Casulli’s staggered scheme, so the eta update is an exact edge-flux finite-volume continuity step (mass conserved to CG tolerance + round-off). eta lives at the triangle CIRCUMCENTRE. The step:

  1. save U^n (u_edge -> u_n_edge) and form eta^n = stage_cv at circumcentres (stage = h + b already; eta == stage);
  2. build per-edge frozen effective depths Hf (wall edges 0, Dirichlet edges real) + the per-edge Dirichlet ghost eta;
  3. EDGE predictor U_e = U^n_e - g(1-theta)dt*edge_flux(Hf,eta^n)
    • wind, gated on Hf>0 (dead edges => exactly 0);
  4. theta-blend RHS from the edge transports (+ Dirichlet ghost fold);
  5. area-weighted CG solve of the SPD TPFA Helmholtz for eta^{n+1} (warm-started from eta^n; the load-bearing area weight);
  6. EDGE back-substitution U^{n+1}_e = U_e - gthetadtedge_flux(Hf, eta^{n+1}) — the identical frozen Hf the operator used, so the edge transports satisfy discrete continuity EXACTLY;
  7. reconstruct the A-grid cell momenta (Green-Gauss from the edge normals) for the KNP seam + recover h^{n+1} = eta^{n+1} - b.

Single-rank, owned-cell loops (no per-CG-iteration halo). The step ends with barotropic stage_cv/xmom_cv/ymom_cv/height_cv valid, so BCs, diagnostics, output, gauges work unchanged.

public pure subroutine si_unstr_reconstruct_cell_momenta(mesh, nct, nco, u_edge, xmom, ymom)

Least-squares reconstruction of the cell-centre transport vector (hu, hv) from the three edge-normal transports U_e = (hu,hv)·n_e: M = sum_e len_e * n_e n_e^T, rhs = sum_e len_e * U_e * n_e, (hu, hv) = M^{-1} rhs. Exact for a constant transport field (the three normals span R^2 on a non-degenerate triangle => M SPD, invertible). The KNP seam only needs a diagnostic cell momentum; eta/mass already closed on the edges. Shared by the 2D step and (per layer) the ML step.

public subroutine si_unstr_step(state, mesh, dt, iter_out)

Advance the 2D barotropic free surface one semi-implicit step on the triangulation. Reads the frozen Hf / ghost from the current surface, solves the Helmholtz eta-system, and back-substitutes the edge transports. iter_out returns the CG iteration count (summed over the Newton outers in wet/dry mode).

private subroutine si_unstr_advance_wetdry(state, mesh, nct, nco, n_bc, dt, theta, g_theta2_dt2, gtheta_dt, g_omtheta_dt, iter_out)

One Casulli wetting/drying SI step on the triangulation — the Newton wrapper around the area-weighted TPFA CG (the structured si_advance_wetdry, edge-wise; V/a/Newton per-cell, prototype- confirmed mesh-agnostic). The nonlinear system is F(eta) = v(eta) + T*eta - rhs_d = 0, J = diag(a+floor) + T with T the SAME frozen-Hf stiffness the linear code has (gated-mean edge depths — all-wet reduces exactly to the linear edge depth) and the constant mass 1 replaced per cell by the wet fraction a. V convex => plain Newton converges monotonically (no line search).
