public subroutine ml_equation_of_state_shared(h_layer, hS_layer, hT_layer, rho_layer, eos, grid, nz)

Opt-in coastal entry to the SHARED (ocean) equation of state — selected by &tracer_nml eos_form = "wright" | "roquet_spv". Thin forwarding shim onto the regime-agnostic eos_compute_arrays variant dispatch; evaluation is at eos%p_ref (default 0 Pa ⇒ surface/potential density — the right choice for the coastal depth range) with the shared H_VANISHED vanishing-layer fallback to eos%rho0 (note: the legacy coastal kernel gates on DRY_TOLERANCE instead). The eos_t handle is a flat POD — its scalars are read on the host here and passed by value into the device kernels, so no device mapping of the handle is required.
