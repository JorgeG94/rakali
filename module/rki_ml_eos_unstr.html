public pure function rho_ref_at(z, rho_ref, dz, nz_ref, rho_0) result(rho)

Linear interpolation of the reference-density profile at depth z. Out-of-range values fall back to the nearest endpoint. When the profile is unset (dz == 0) returns rho_0 so the kernel reduces to its pre-B2 behaviour.

public subroutine ml_compute_reference_density_unstr(state, mesh)

Build the horizontally-uniform reference-density profile rho_ref(z) from the current rho_layer, sampled on a uniform z-grid 0..rho_ref_dz*nz_ref and area-weighted across owned cells. Subtracted by both BPG kernels so the integrand is the anomaly rho - rho_ref(z), scaling the residual sigma PGE down. Called once at solver init after the first EOS evaluation, on the host (one-time D2H+H2D).

public pure subroutine ml_equation_of_state_shared_unstr(h_layer, hS_layer, hT_layer, rho_layer, eos, nz, n)

Opt-in SHARED (ocean) equation of state on the unstructured (nz, ncells) layout — the axis order is opposite to the structured shim, so this evaluates eos_density_point per (layer, cell) instead of forwarding to the structured 3D impls. eos_density_point is pure + !$acc routine seq and takes the flat-POD eos_t by value, so the handle rides into the kernel as a register copy — no device mapping. Evaluation is at eos%p_ref (default 0 ⇒ surface/potential density).

public subroutine ml_equation_of_state_unstr(state)

Linear two-tracer EOS, per-cell, per-layer: rho_k = rho_0 + beta_S(S_k - S_ref) - alpha_T(T_k - T_ref) with S_k = hS_k/h_k, T_k = hT_k/h_k. Dry layers fall back to the reference state. Computed over all cells (interior + halo) so the BPG gradient kernel reads neighbour rho without a separate halo.
