restart_read_unstr restart_write_unstr

Writes and reads checkpoint files for the unstructured solver. Stores (stage_cv, xmom_cv, ymom_cv, bed_cv) for owned cells, plus simulation time and step count as global attributes.

File format: NetCDF-4 with one dimension face = ncells_owned. Cell global ids stored if available.
