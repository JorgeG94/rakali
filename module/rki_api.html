integer(kind=c_int), private, parameter :: RKI_ERR_BAD_HANDLE = -100

State machine for GPU data lifecycle (h%on_device, h%host_is_current): (F, F) — initial / after destroy (T, F) — after finalize/step/advance (GPU canonical) (T, T) — after rki_sync_host (both valid) (F, T) — after ensure_host/exit_data (host only)

Transitions: rki_finalize -> (T, F) rki_step/advance -> (T, F) rki_sync_host -> (T, T) ensure_host -> if host_is_current: no-op; else (F, T) ensure_device -> (T, F) rki_destroy -> handle freed

private function rki_working_precision() result(nbytes) bind(c, name="rki_working_precision")

Working-precision width in bytes (8 = double, 4 = single) for the solver real kind wp. Process-global (compile-time), handle-less: lets the Python/ctypes layer pick the numpy dtype matching the zero-copy field views, which are c_loc of real(wp) arrays. Shared by the structured and unstructured Python paths (one symbol in librakali, since wp is identical for both).

Arguments

None

Return Value integer(kind=c_int)
