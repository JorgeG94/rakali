public subroutine init_gaussian_hump(s, h0, amplitude, sigma, x_off, y_off, u_shear)

Initialise a Gaussian hump perturbation. When u_shear /= 0 and NH is enabled, the top layer gets +u_shear and the bottom -u_shear (vertical shear → non-zero vorticity). Bathymetry preserved if already loaded. Public only for the unit-test suite.

public subroutine init_still_water(s, eta0)

Initialise a flat free surface at elevation eta0: h = max(eta0 - b, 0) everywhere, zero velocity. Requires bathymetry already loaded into s%barotropic%b. Public only for tests.

public subroutine refresh_multilayer_derived(s)

Recompute the multilayer fields that are derived from the layer thicknesses and tracers: the equation of state (rho_layer) and the reference-density profile (rho_ref) that the baroclinic pressure-gradient kernels subtract.

public subroutine restore_multilayer_after_restart(s)

A restart file restores the prognostic multilayer fields (layer thicknesses, momenta, tracers) but not the derived ones. Rebuild the z*-full reference levels and the density / reference-density profile so a warm start sees the same state a continuous run does.
