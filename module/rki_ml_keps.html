Standard two-equation k-epsilon model (Launder & Spalding 1974; constants per Rodi 1987 / Warner et al. 2005): dk/dt = d/dz(nu_t/sig_k dk/dz) + P + B - eps deps/dt = d/dz(nu_t/sig_e deps/dz) + (eps/k)(ce1 P + ce3 B - ce2 eps) nu_t = c_mu k^2/eps, kappa_t = nu_t/Pr_t, P = nu_t S^2, B = -kappa_t N^2

Staggering (bottom-up): velocity/density at layer centres (1..nz); k, eps, nu_t, kappa_t at interfaces (1..nz+1, 1=bed, nz+1=surface). Diffusion implicit (Thomas), dissipation sinks semi-implicit (Patankar) for positivity. One do concurrent over columns; sequential vertical sweep with NZ_STACK_MAX stack workspace.

public pure subroutine ml_keps_apply_diffusion_tracer(h_layer, hTr, kt, kappa_bg, grid, nz, dt)

Implicit (Thomas) vertical diffusion of one tracer using k-eps diffusivity kt (interface-shaped) plus background floor kappa_bg. No-flux at bed/surface (surface tracer fluxes are a separate kernel); conserves column tracer content sum_k hTr_k exactly. Implicit (not explicit PP81) because kt can reach NUT_MAX. Pass tracers(it)%hTr.

public pure subroutine ml_keps_apply_momentum(h_layer, hu_layer, hv_layer, nut, grid, nz, dt)

Apply k-epsilon eddy viscosity nut (interface-shaped nz+1, from ml_keps_update) to layer momentum via an implicit (Thomas) vertical- diffusion sweep. No-flux at bed/surface (wind stress and bottom drag are separate kernels); conserves column total sum_k h_k u_k exactly. Implicit (not explicit PP81) because nu_t can reach NUT_MAX. One do concurrent over columns; shared matrix, two RHS (u, v).

public pure subroutine ml_keps_friction_velocities(wind_x, wind_y, h_layer, hu_layer, hv_layer, manning_n, use_linear_drag, drag_r, rho_0, ustar_s, ustar_b, grid, nz)

Per-column surface and bed friction velocities feeding the k-eps wall functions (ml_keps_update). surface: u_s = sqrt(|tau_wind| / rho_0), tau_wind = (wind_x, wind_y) the wind-stress components (Pa). bed: from the active bottom-drag law — quadratic Manning u_b = sqrt(C_d)|u_b|, C_d = g n^2 / H^(1/3); or linear (Rayleigh) u_b = sqrt(r * h_b * |u_b|). Bottom velocity is the k=1 (bed) layer; H is the column depth.

private pure subroutine keps_tridiag_solve_noflux(a, b, c, rhs, cp, n)

In-place Thomas solve over rows 1..n with the boundary closure already baked into a/b/c by the caller (no row override, unlike keps_tridiag_solve). rhs returns the solution; cp scratch. a/b/c are read-only so one factorisation can serve multiple RHS.
