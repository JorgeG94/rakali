Per-tracer state and config for the unstructured multilayer solver. Mirrors rki_tracer (structured) field-for-field; only the array axis order differs. Cell-centric layout puts nz first to match the rest of the unstructured multilayer fields (h_layer(nz, ncells_total) etc.).

Holds the prognostic field hTr (= h * Tr), the RK2 save buffer hTr0, and all scalar config the kernels consume. Designed so the solver can iterate do it = 1, size(state%tracers) and dispatch the generic ml_*_tracer_unstr kernels per element.
