Container for the centroid conserved variables, the edge reconstruction scratch, the per-step accumulators, RK2 saves, Chapman persistent state, the per-edge mass flux consumed by tracer CWC, and the small set of barotropic physics scalars (Manning’s n, uniform wind stress).

Lives at state%barotropic. Multilayer code reads mass_flux_e from here (CWC tracer advection); the layer-distribute kernels also read stage_cv / xmom_cv / ymom_cv / bed_cv to compute new layer states. Mirrors structured barotropic_state_t.
