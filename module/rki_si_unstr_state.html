Persistent workspace for the semi-implicit (Casulli) free-surface mode on the UNSTRUCTURED (triangular) backend (time_scheme="semi_implicit", grid_type="unstructured"). The semi-implicit workspace for the unstructured backend; allocated only when the mode is on and living at state%si on unstr_state_t.

GEOMETRY OF RECORD (cell-centred FV on a triangulation, prototype si_unstr_proto.py): eta lives at the triangle CIRCUMCENTRE (mesh circumcentre_x/y, NOT the centroid the KNP path uses); the SI face transports live on EDGES. A triangle’s three edges are stored in the (3, ncell) per-edge-of-cell layout (edge i opposite vertex i) — the same double-visit layout as the KNP flux path: each cell owns its 3 edge values, interior edges are computed twice (no scatter, no atomics, GPU-race-free).

THE LOAD-BEARING CG DETAIL: the cell-centred FV Helmholtz operator is self-adjoint in the AREA-WEIGHTED inner product <x,y> = sum_c area_c x_c y_c, NOT the plain dot (variable cell areas scale the rows). The CG/Jacobi dot products carry the mesh%area weight; the residual gate uses the area-weighted norm. Get it wrong and the operator is non-symmetric and CG stalls. Uniform area recovers the structured harness. (See rki_si_unstr_helmholtz.)

All CG vectors are (ncell); the per-edge workspaces are (3, ncell). The enter_data/exit_data methods attach the arrays to the device; the parent unstr_state_t struct is mapped by state_unstr_enter_data BEFORE this runs (same discipline as the structured si slot).

integer, public, parameter :: SI_PRECOND_JACOBI = 1

Diagonal (Jacobi) PCG: z = eta_diag*r. Matters MORE on triangles than on the structured grid — variable cell areas put real disparity on the Helmholtz diagonal even at uniform depth (measured diag spread O(100-1000)x on a jittered basin; ~2.5x iteration win — prototype study 4).
integer, public, parameter :: SI_PRECOND_MG = 2

Aggregation (agglomeration) multigrid V(2,2)-cycle PCG — the triangle plateau-breaker (rki_si_unstr_mg). Greedy pairwise cell-graph coarsening + Galerkin coarse operators + damped-Jacobi smoothing; numpy-prototype-validated to collapse the plain-CG plateau of thousands to tens of iters (Q12). Opt-in; the hierarchy mg slot is built at enable_si and refreshed once per step.
integer, public, parameter :: SI_PRECOND_NONE = 0

Unpreconditioned CG (area-weighted plain CG).

private subroutine si_unstr_state_init(this, mesh, nz, wetdry, n_sub)

Allocate workspace arrays at the mesh size, zero-filled. When nz is present and > 1 the P3.2 (3D multilayer) column slots are also allocated; when wetdry is present and .true. the P3.3 Casulli wet/dry slots are (with n_sub sub-bottoms, default 1); otherwise only the 2D barotropic slots exist and the 2D path is unchanged. Plain host allocation (runs before enter_data, so a device loop would round-trip).
