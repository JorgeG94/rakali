Subroutines
apply_sponge_unstr

Explicit volumetric damping of h and momentum toward a reference state at cells adjacent to boundary edges tagged BC_SPONGE.

Algorithm: for each owned cell, scan the three edges. If any edge is a boundary edge (mesh%neighbours(e, cell) < 0) belonging to a BC_SPONGE group, collect the group’s strength [1/s] and h_ref [m]. When multiple sponge edges exist (a corner cell), use the maximum strength and its paired h_ref. Then apply one forward- Euler relaxation step:

h <- h - dtalpha(h - h_ref) xmom <- xmom(1 - dtalpha) ymom <- ymom(1 - dtalpha)

where h = stage_cv - bed_cv and alpha = bc_sponge_strength(g).

The kernel self-gates: cells not adjacent to any active BC_SPONGE edge are skipped implicitly (alpha stays at 0). No-op when strength <= 0 for all sponge groups.

v1 limitation: the sponge band is one cell deep — only cells with a direct boundary edge are affected. Graded-width profiles require cell-distance information that is not available on triangular meshes without additional mesh topology data. On the structured side the distance is implicit in the (i,j) indices; no such shortcut exists here. Multi-cell sponge widths are deferred.
