Container for the spatially-varying surface forcing fields applied by the unstructured multilayer pipeline. Currently only the two tracer-side forcings are supported:

heat_flux net surface heat flux (W/m^2, positive into ocean) applied to the top layer’s hT field via hT(1,c) += dt * Q / (rho_0 * cp).

evap_minus_precip virtual surface freshwater flux (m/s, positive for net evaporation) applied as a virtual salt flux on the top layer: hS(1,c) += dt * (E-P) * S_top. Does not change h_layer – pure tracer forcing in the ROMS / MOM convention.

wind_x / wind_y per-cell surface wind STRESS (Pa) added to the barotropic momentum in the fused update kernel: hu += dt * wind_x / RHO_WATER, on top of the spatially-uniform barotropic%wind_tau_*. Pushed per owned cell via rki_unstr_set_wind_field.

Atmospheric pressure / precipitation will be added when those ports land; this container will gain them to mirror surface_forcing_t.

type, public ::  unstr_surface_forcing_t

Surface flux fields applied by the unstructured multilayer surface-flux kernel. Sized to mesh%ncells_total so halo cells carry whatever the user pushed in (forcing is read-only from the kernel’s perspective and only owned cells are written into tracer fields, so halo content is irrelevant for correctness – but the allocation matches the rest of the state for consistency).

private subroutine unstr_surface_forcing_enter_data(this)

Map the forcing allocatables onto the device. The parent unstr_state_t%forcing value-type member rides over with the parent copyin(state); only the inner allocatable arrays need explicit attaches. Both fields are read-only in the kernel and updated from host via set_* setters, so copyin is the right initial direction.
