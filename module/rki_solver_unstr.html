Two-stage strong-stability-preserving Runge-Kutta time loop for the unstructured central-upwind solver. Based on the evolve step (shallow_water_domain.py:2000-2100):

backup Q^n stage 1: extrapolate, flux, update(dt), protect -> Q stage 2: extrapolate, flux, update(dt), protect -> Q* saxpy(0.5, 0.5) -> Q^{n+1} protect

Two public entry points:

  • solver_unstr_step(state, mesh, dt) – one SSP-RK2 step at a caller-supplied dt. The driver does NOT call the CFL kernel here; this is the right granularity for the future hybrid driver, which will own the global timestep across structured + unstructured halves and pass it in.

  • solver_unstr_advance(state, mesh, t_end) – step until state%time >= t_end, recomputing dt from CFL each step (or every cfl_interval steps once that knob is plumbed through). Convenience wrapper for tests and stand-alone runs.

Both entry points assume the data has already been entered onto the device. The caller is responsible for the mesh_unstr_enter_data / state_unstr_enter_data / ..._exit_data lifecycle. This matches the structured solver’s convention (solver_step does not touch enter/exit_data; the API layer handles it once at simulation start and end).

private subroutine solver_unstr_step_semi_implicit(state, mesh, dt)

One semi-implicit (Casulli) free-surface step on the triangulation. Hands the conserved variables to si_unstr_step, which owns the frozen-Hf predictor -> TPFA Helmholtz eta-solve -> edge back-substitution -> A-grid cell momentum reconstruction, plus the time/step bookkeeping. Open-edge Dirichlet coupling (tidal / clamped) is read inside the step from state%bc_type / state%bc_eta_ext (the coefficient-space route); wall edges get Hf=0 (no-flux Neumann). The caller sets bc_eta_ext to the prescribed surface (tests evaluate the tide at the theta-weighted time). The step ends with barotropic stage_cv / xmom_cv / ymom_cv / height_cv valid — downstream unchanged.
