Per-layer prognostic arrays, vertical-coordinate definition, diagnostic vertical velocity, EOS-derived density + reference profile, tracer registry, and the scalar physics params the multilayer kernels read (vmix, Smagorinsky, BPG/PPM flags, EOS). Lives at state%multilayer; allocated by state_init only when use_multilayer = .true. (else only scalar defaults).

private subroutine multilayer_build_vcoord_reference(this, barotropic, grid)

For VCOORD_ZSTAR_FULL, build the per-column reference z-level pattern vcoord_z_ref_col from the bathymetry. No-op for the other vertical coordinates. Needed both on a cold start (called by init_layers) and after a restart read, which restores the prognostic layer fields but not this derived array.

private subroutine multilayer_init_layers(this, barotropic, grid)

Lay out the initial per-layer distribution from the barotropic state: for VCOORD_ZSTAR_FULL first build the per-column reference z-level pattern from the bathymetry, then split the barotropic (h, hu, hv) across layers via the sigma weights dsig_ml. Call once after init and before seed_tracers / EOS.

private subroutine multilayer_register_passive_tracer(this, grid, name, tr_init, tr_min, tr_max, kappa_bg, hdiff_kappa)

Append a passive tracer (eos_coeff = 0) to the registry, growing tracers(:) past the default S/T pair. Must be called AFTER init and BEFORE the solver’s enter_data (so the new hTr gets device-mapped) — enforced via registry_locked: once the solver has mapped the registry the call logs an error and returns without touching it. Caller populates hTr once layer thicknesses are known. S/T keep their indices.

private subroutine multilayer_state_init(this, grid)

Allocate all multilayer arrays at the grid size and configured layer count, init the vcoord object, copy vcoord%z_ref into the GPU-mappable vcoord_z_ref, allocate the rho-ref profile, and register S + T. Caller must set nz_ml, vcoord%coord_type, vcoord%remap_method, and any other vcoord parameters first.
