Casulli (2009) subgrid wetting/drying for the unstructured semi-implicit free-surface mode — ported per-cell ((n_sub, ncells) sub-bottom layout) exactly as the prototype confirmed mesh-agnostic (si_unstr_proto.py study 2: V/a/Newton + the edge sill rule ran UNCHANGED on triangles). Replaces the linear solver’s constant 1.0 cell-mass term by the exact wetted-volume function per unit cell area (depth units):

v_c(eta) = (1/n_sub) sum_s max(eta - b_c^(s), 0) (mean wet depth) a_c(eta) = v’_c(eta) in [0,1] (wet fraction)

driving a PLAIN Newton outer loop (V convex => monotone finite convergence) around the SAME area-weighted TPFA CG, with the operator’s mass term replaced per cell by a(eta) + floor (the mass_diag argument already threaded through si_unstr_apply_helmholtz / si_unstr_cg_solve).

FROZEN edge rule (Casulli, rule R1) — the GATED-MEAN conveyance: Hf_e = 0.5(max(eta_L-b_L,0) + max(eta_R-b_R,0)) gated to 0 unless max(eta_L,eta_R) > max(b_L,b_R) built ONCE from eta^n and held over the step, shared by the operator, back-substitution and RHS (R2). Where both cells are wet this reduces EXACTLY to the linear edge depth 0.5(h_L+h_R) — the all-wet self-consistency invariant. Dead edges (higher surface below the sill) become walls; their U^n edge transports are zeroed at step start (R3 — structural on this backend: the RHS consumes per-edge transports directly, so zeroing u_star/u_n_edge on Hf=0 edges closes the dead-edge flux exactly; no cell-momentum reconstruction masking is needed, unlike the structured path). Dry-cell eta is NOT clamped at the bed — Newton lets it settle below (V = 0 regardless).

References: Casulli (2009) IJNMF 60:391-408; Casulli & Zanolli (2010) SISC 32(4):2255-2273.

All kernels explicit-shape (n_sub|3, ncells), device-resident, cell-index-last per the unstructured convention.

public pure subroutine si_unstr_wetdry_face_depths(mesh, nct, nco, n_bc, eta, b_min, bc_type, bc_eta_ext, Hf_edge, eta_ghost_edge)

FROZEN wet/dry edge depths — the GATED-MEAN conveyance rule per edge (Casulli rule R1, prototype-verified mesh-agnostic): wet <=> max(eta_L, eta_R) > max(b_L, b_R) (max-eta/sill) Hf = 0.5(max(eta_L-b_L,0) + max(eta_R-b_R,0)) where wet Where BOTH cells are wet this is EXACTLY the linear edge depth 0.5(h_L+h_R) — an all-wet basin reproduces the linear operator’s Hf bit-for-bit (NOT a raw max-eta or bare sill depth, which would change the all-wet answer — the load-bearing structured lesson). Dead edges (higher surface below the higher bed — a wet cell cannot “see” through a dry one over the sill) are walls (Hf=0).

public pure subroutine si_unstr_wetdry_fill_bsub(mesh, nsub, nct, nco, bed, bsub_fill, b_sub, b_min)

Fill the per-cell sub-bottom table from the plain bed. v1 (n_sub=1): b_sub(1,:) = bed, b_min = bed — always, regardless of mode. Subgrid (n_sub>=2): FLAT (default): all sub-bottoms = bed => BIT-IDENTICAL to n_sub=1. LINEAR: nsub equal-area sub-bottoms evenly spaced across the per-cell relief band [bed-half, bed+half], half = 0.5*max edge-neighbour |Δbed| (a linear sub-cell bed ramp; Casulli 2009 subgrid bathymetry, prototype subgrid_bathy_from_bed). Sub-bottoms ascending; mean == bed (still-water volume unchanged); wet fraction staircases 1/nsub per breakpoint so a coarse tidal flat drains/floods SMOOTHLY. Boundary edges (no neighbour) contribute 0 to the relief so a shore cell falls back toward FLAT. On flat bed (half=0) => == FLAT. b_min = the deepest (first, sill) sub-bottom.

public pure subroutine si_unstr_wetdry_mass_diag(nct, nco, a_cell, Hf_edge, mass_diag)

Assemble the Newton mass diagonal M = a + floor (Casulli R5): the wet fraction a plus a +1 identity for a fully-decoupled dry row (a <= tol AND all three edge stiffness coefficients Hf <= tol). The +1 matches the linear operator’s constant mass exactly at wet cells where a == 1 and no floor fires.

public subroutine si_unstr_wetdry_newton_residual(nct, nco, eta, Jeta, mass_diag, v_cell, rhs, res, res2_out)

Form the Newton nonlinear residual and its squared interior norm: F_c = v_c(eta) + [T eta]_c - rhs_c, with the stiffness recovered matmul-free from the full mass-diag operator apply: Teta = Jeta - mass_diageta. Returns sum(F^2) over the owned cells (the Newton convergence norm — plain, not area-weighted, matching the prototype/structured gate; it is a convergence heuristic, not the CG inner product).
