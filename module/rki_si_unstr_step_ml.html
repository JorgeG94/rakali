One semi-implicit (Casulli/SCHISM-style) step for the UNSTRUCTURED 3D multilayer coastal path (time_scheme="semi_implicit" + use_multilayer, nz>1, sigma) — built on the P3.1 TPFA eta-solve (the operator never changes; only the Hf/Gbar fills do — the “strict superset” contract) and the (nz, ncells) column kernels of rki_si_unstr_column. The step (one implicit theta-step; the theta scheme IS the integrator):

  1. save U^n edges + layer state; eta^n = stage at circumcentres;
  2. explicit predictor tendencies IN PLACE on hu/hv_layer: baroclinic PGF, Coriolis, Smagorinsky (existing unstructured kernels), and surface wind stress on the TOP layer (k=nz) — dt*tau/RHO_WATER from the uniform scalar wind (rides the pure-u^n predictor into G_k; R_k / Hhat / the operator are untouched by linearity; no momentum self-advection — the SI target regime is advection-weak, same envelope as structured);
  3. PP81 interface viscosity + per-column implicit solve (G_k, R_k, Hhat = -sum h_k R_k, Gbar = sum h_k G_k);
  4. Hf from Hhat via the P3.1 edge face-depth kernel reused verbatim (Hhat passed as the cell “depth”; a Dirichlet edge gets 0.5*(Hhat_c + h_ghost) with h_ghost = eta_bc - b — the structured ghost-Hhat seed, edge-wise), edge predictor from the face-averaged Gbar, theta-blend RHS + area-weighted CG — ALL P3.1 machinery reused verbatim;
  5. per-layer edge-transport recovery (column sums telescope EXACTLY to the 2D back-substituted edge transport => mass to round-off; Dirichlet ghost R = -1 seed inline — the estuary-mouth lesson);
  6. tracers: every registry tracer advected depth-proportionally with the EXACT blended edge mass flux the eta update used (uniform tracers invariant per layer; OUTER SHIM: the host registry loop passes tracers(it)%hTr/hTr0 into the flat-impl kernel — the array-of-derived-types device rule);
  7. h^{n+1} = eta^{n+1} - b; h_layer = dsig*h; per-layer cell momenta = least-squares edge reconstruction; barotropic momenta = layer sums; U^{n+1} edge prognostic = column sums;
  8. tracer vertical diffusion, surface fluxes, clamp, EOS — the existing unstructured kernels reused as-is. NO diasurface exchange: the dsig-proportional advection makes sigma surfaces material for the transported fields (the structured design decision, carried over).

The step ends with valid barotropic stage/xmom/ymom/height + multilayer *_layer state — downstream (output, gauges, restart) unchanged. Single-rank, owned-cell loops.

private pure subroutine si_ml_wetdry_face_depths(mesh, nct, nco, n_bc, eta, b_min, Hhat, bc_type, bc_eta_ext, Hf_edge, eta_ghost_edge)

Frozen wet/dry edge depths for the 3D column-integrated eta-solve — the triangular twin of the structured si_ml_wetdry_face_depths: the effective CONVEYANCE is the Hhat-based two-cell average (as the all-wet ML path uses), GATED by the geometric max-eta/sill wet/dry rule so an edge dead by geometry (higher surface below the higher bed) carries Hf=0 — a wall — regardless of Hhat. The surface geometry decides wet/dead; where wet, the implicit column response Hhat sets the conveyance magnitude. b_min = the geometric sill bed (deepest sub-bottom). Dirichlet edges gate the ghost-coupled face the same way (ghost surface = the prescribed eta_bc; ghost sill mirrors the cell sill). All-wet Hhat basins reduce this EXACTLY to the P3.1 si_unstr_face_depths conveyance (0.5*(Hhat_c+Hhat_nbr)), so the wet/dry branch is a strict superset. Cell-centric double-visit (3,ncell), cell-index-last.

private subroutine si_ml_wetdry_newton(state, mesh, nct, nco, g_theta2_dt2, iter_out)

Newton outer loop for the 3D column-integrated wet/dry eta-solve on the triangulation — the triangular twin of the structured si_ml_wetdry_newton (and the 2D-unstr si_unstr_advance_wetdry’s Newton loop). The column responses (g_col/r_col/Hhat/Gbar) and the frozen Hf are held FIXED (they depend on h_layer at time n, not eta), so only the surface mass system F = v(eta) + T*eta - rhs_d iterates, with T the Hhat-weighted TPFA stiffness and the surface wet-fraction Newton diagonal a(eta)+floor. On entry state%si%eta_r holds the LINEAR RHS (leading eta^n from si_unstr_compute_rhs); this swaps the leading term for v(eta^n) once, then Newton-solves. Host-side orchestration; flat device kernels. Writes state%si%newton_iters and state%si%mass_res = the NONLINEAR mass residual ||F||^2 at Newton exit (the conservation diagnostic — NOT the inner-CG residual of the last delta-solve, which is an internal solver number).
