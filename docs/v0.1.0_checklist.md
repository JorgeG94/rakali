## Shared numerics

- [ ] **WENO-5/7/9 tracer advection** — extends the existing PCM/PLM/PPM
  reconstruction ladder.  One shared 1D reconstruction core + thin
  per-site adapters (avoid re-triplicating like PPM did across remap and
  tracer advection).  Open decisions: unstructured
  target order (5/7/9 doesn't port cheaply to triangles — cap at WENO-3 or
  stay 2nd-order?), runtime- vs compile-time order, halo width grows with
  order (`nghost` 2 → 3/4/5).  Deep design → `docs/weno_tracer_plan.md`
  when we start it.
- [x] **Vertical coordinates / ALE machinery** — sigma / zsigma / zstar /
  zstar_full / zstar_sigma wired + remapped + tested (shared `src/ALE/`).
- [ ] **Lift lazy `*_workspace_ensure` scratch onto state slots** — finishes
  the pure-procedure sweep (Tier A host helpers + Tier B do-concurrent kernels
  + Tier C orchestrators already landed).  Four hot kernels still hide an
  `allocate` + `!$acc enter data create` behind a lazy-ensure helper, which
  blocks the `pure` attribute:
  `ml_advect_tracer_ppm` (`ppm_workspace_ensure`),
  `ml_horizontal_diffusion_tracer` (`hdiff_workspace_ensure`),
  `ml_horizontal_viscosity_smag` + `ml_horizontal_viscosity_biharmonic`
  (`horvisc_workspace_ensure` / `bih_workspace_ensure`).  Pattern to follow:
  the ALE remap slots (`vcoord%remap_total_h` / `remap_h_ref` / `remap_h_old`),
  allocated once at init, freed at destroy, no per-call lifecycle.

## Coastal

- [x] **KPP vertical mixing** — a full KPP overlay (`rki_ml_kpp`:
  BL-depth, shape fns, shear + convective, non-local γ, V_t²) on both
  backends as a fused overlay on the explicit PP81 flux,
  gated by `vmix_use_kpp` (default off → bit-identical to PP81).
  - [x] **structured A-grid** (`rki_ml_kpp`) — `test_coastal_kpp`, green gfortran + NVHPC GPU.
  - [x] **unstructured parity** (`rki_ml_kpp_unstr`) — cell-centric two-pass kernels;
    u_* reads the existing uniform `wind_tau`; `rki_unstr_set_kpp` C API + Python `set_kpp()`.
- [x] **k-ε vertical mixing (structured)** — clean-room two-equation closure
  (TKE + ε transport, ν_t = c_μ·k²/ε), implicit tridiagonal vertical diffusion
  (Thomas), log-law wall functions at bed (k=1) + surface (k=nz), momentum +
  tracer mixing, surface-concentrated wind-stress option (`wind_surface_layer`).
  Gated by `vmix_use_keps` (default off → bit-identical to PP81).  Validated
  against the Kato-Phillips √t mixed-layer deepening law.  PR #194.
  - [x] **unstructured k-ε port** — `rki_ml_keps_unstr` (cell-centric column
    kernel + apply kernels + friction velocities), wired into `rki_solver_unstr`;
    `test_keps_unstr` + `test_keps_kato_unstr` (Kato-Phillips √t).
  - [x] **stratification-aware stability functions** — shared backend-agnostic
    `rki_keps_stability` ships all three: constant, Galperin (1988), Canuto (2001;
    Umlauf & Burchard 2003 rational form).  Both backends dispatch on
    `keps_stability` (`test_keps` + `test_keps_unstr`).
- [x] **Generalize tracers to the registry (structured + unstructured)** —
  `multilayer%register_passive_tracer(...)`; the ALE remap split into a
  momentum/thickness `ml_distribute_with_remap{,_full}{,_unstr}` + a per-tracer
  `ml_remap_tracer{,_unstr}` looped over `tracers(:)`; both solvers now loop every
  passive-transport kernel over the registry (advection, ALE remap, vertical +
  horizontal diffusion, conservative clamp, vertical exchange, BCs, RK2).  A 3rd
  passive tracer tracks salinity bit-for-bit on both backends.  Surface tracer
  flux + EOS stay S/T-specific *by design*.
  - [ ] nz=1 fused fast path still S/T-only (structured; extras need nz>1)
- [x] **Stratified IC (linear T(z) + S(z))** — `T_init_surface` / `T_init_bottom`
  and `S_init_surface` / `S_init_bottom` seed linear temperature / salinity
  profiles (bed `k=1` → surface `k=nz`), each gated default-off so the uniform
  path stays bit-identical.  The two tracers gate
  independently and share one tracer-agnostic seed kernel.  Stable polarity is
  inverse: warm-over-cold for T (`T_surface > T_bottom`), fresh-over-salty for S
  (`S_bottom > S_surface`).
  - [x] **unstructured coastal** — `ml_init_tracer_stratified_unstr`, gated in
    `solver_unstr_init_multilayer` for both S and T; `coastal_unstr.nml`
    stratifies T+S so the bench exercises EOS / BPG / Ri vmix; analytical tests
    `tracer_init_stratified_linear_profile` (T) + `salinity_init_stratified_linear_profile`
    (S, river-plume polarity), green on both backends.
  - [x] **structured coastal parity** — `ml_init_tracer_stratified` (mirrors the
    unstructured kernel), `T_init_*` / `S_init_*` carried on `multilayer_state_t`,
    gated seeds wired into both structured init paths (`rki_init` namelist +
    `rki_api` FFI); `coastal_str.nml` now stratifies T+S to match
    `coastal_unstr.nml`.  Analytical test `init_tracer_stratified_linear_profile`
    in `test_multilayer`.
- [~] **Sediment transport** — a sediment *model* on top of the generic tracer
  plumbing.  Single-class suspended **shipped (structured, PR #192)**: settling
  velocity (PPM augmented-column vertical sinking flux), Partheniades-Krone /
  Ariathurai bed exchange (erosion above critical stress + deposition), and a
  `bed_sediment` mass reservoir that conserves suspended + bed total.
  - [ ] **unstructured parity**
  - post-v0.1.0: multiple size/density classes, bedload + Exner, morphodynamic
    bed-level feedback into bathymetry (bed is a mass reservoir only in v0.1.0)
- [ ] **Gridded / per-grid forcing** — real-bathymetry coastal runs need
  spatial forcing, not analytical:
  - **Gridded wind**: NetCDF 10m-wind → stress reader exists (`rki_forcing`,
    space + linear-time interp into `forcing%wind_x/y`) and **structured**
    kernels consume it per-cell.
    - [x] **unstructured per-cell consumption** — `surface_forcing_unstr` gained
      per-cell `wind_x/wind_y` (Pa); fused update applies `dt*(wind_tau +
      wind_x(cell))/RHO_WATER`; `rki_unstr_set_wind_field` C API + Python `set_wind_field()`.
    - [ ] NetCDF→triangle-centroid interpolation deferred — the `rki_forcing`
      reader is structured-(i,j)-only; on the API-push unstructured path the
      caller interpolates onto centroids (Python) and pushes via set_wind_field.
    - [ ] KPP u_* still reads the uniform `wind_tau` (per-cell wind doesn't feed KPP mixing yet).
  - **TPXO tides**: no TPXO/OTPS ingestion today — coastal tides are namelist
    `tidal_amp/phase/omega` only.  Build a TPXO constituent reader → interpolate
    to the open-boundary nodes → drive `BC_TIDAL` (+ optional body-force tidal
    potential), both backends.

## Beyond v0.1.0 — release lines

- **v0.2.0 — Waves via SWAN coupling.**  The one deliberate external coupling.
  Exchange: Rakali → currents + η to SWAN; SWAN → radiation-stress gradients
  (momentum forcing) + wave-enhanced bottom stress / orbital velocity (bottom
  friction + **sediment resuspension**, ties into the coastal sediment item).
  Coupling mechanics (grid interp, exchange cadence, framework vs file vs direct
  API) TBD.  Detailed wave options → `ROADMAP_COASTAL.md` §12.
- **v1.0 — Native GPU-accelerated wave model.**  Replaces the SWAN dependency;
  brings waves fully in-house (no coupler).  → `ROADMAP_COASTAL.md` §12C.

**Out of regime (not planned):** submesoscale / eddy closures — the coastal
regime doesn't need them.
