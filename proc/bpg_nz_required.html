bpg_nz_required

public pure function bpg_nz_required(nz) result(req)

Smallest BPG_NZ_MAX that safely covers an unstructured multilayer run of nz layers.

nz + 1. Derived from a survey (2026-08) of every BPG_NZ_MAX-dimensioned local in the unstructured kernels; the binding consumer is the one that indexes a plainly-BPG_NZ_MAX array to nz + 1 rather than the BPG_NZ_MAX + 1 an interface array would use:

  • rki_ml_keps_unstr ml_keps_update_unstr_impl S2/N2/dz_if/a/b/c/rhs/cp — written and read at ni = nz + 1 (interface-indexed; keps_tridiag_solve_u touches rows 1..ni of all five solver arrays).

Every other consumer needs only nz:

  • rki_ml_pressure_unstr p_int/p_int_nbr — max index nz (the interface arrays z_if/p_if/zn_if_e/pn_if_e are declared BPG_NZ_MAX + 1 and carry their own slack).
  • rki_ml_tracers_unstr v_layer/hf_layer/frac — max nz; flux_iface — max nz - 1.
  • rki_ml_dynamics_unstr, rki_ml_vertical_viscosity_unstr, rki_ml_kpp_unstr flux_*_iface — max nz - 1.
  • rki_ml_keps_unstr momentum/tracer applies a/b/c/ru/rv/r/cp — max nz.

      !! Smallest `BPG_NZ_MAX` that safely covers an unstructured
      !! multilayer run of `nz` layers.
      !!
      !! `nz + 1`.  Derived from a survey (2026-08) of every
      !! `BPG_NZ_MAX`-dimensioned local in the unstructured kernels; the
      !! binding consumer is the one that indexes a plainly-`BPG_NZ_MAX`
      !! array to `nz + 1` rather than the `BPG_NZ_MAX + 1` an interface
      !! array would use:
      !!
      !!   * `rki_ml_keps_unstr` `ml_keps_update_unstr_impl`
      !!     `S2`/`N2`/`dz_if`/`a`/`b`/`c`/`rhs`/`cp` — written and read
      !!     at `ni = nz + 1` (interface-indexed; `keps_tridiag_solve_u`
      !!     touches rows `1..ni` of all five solver arrays).
      !!
      !! Every other consumer needs only `nz`:
      !!
      !!   * `rki_ml_pressure_unstr` `p_int`/`p_int_nbr` — max index `nz`
      !!     (the interface arrays `z_if`/`p_if`/`zn_if_e`/`pn_if_e` are
      !!     declared `BPG_NZ_MAX + 1` and carry their own slack).
      !!   * `rki_ml_tracers_unstr` `v_layer`/`hf_layer`/`frac` — max
      !!     `nz`; `flux_iface` — max `nz - 1`.
      !!   * `rki_ml_dynamics_unstr`, `rki_ml_vertical_viscosity_unstr`,
      !!     `rki_ml_kpp_unstr` `flux_*_iface` — max `nz - 1`.
      !!   * `rki_ml_keps_unstr` momentum/tracer applies
      !!     `a`/`b`/`c`/`ru`/`rv`/`r`/`cp` — max `nz`.
      integer, intent(in) :: nz
      integer :: req

      req = nz + 1
   end function bpg_nz_required
