ml_apply_tracer_bcs_unstr

public subroutine ml_apply_tracer_bcs_unstr(state, mesh, hTr_layer, bc_tr_ext)

Apply tracer boundary conditions for inflow edges.

For boundary edges where mass is flowing into the domain (inflow), this routine sets the tracer concentration to bc_tr_ext. The value is written into tracer_advect_scratch so that ml_advect_tracer_unstr sees the correct upwind value at inflow boundaries.

Must be called AFTER ml_advect_tracer_unstr has snapshotted hTr_layer into tracer_advect_scratch, but BEFORE the per-cell advection loop runs. Since ml_advect_tracer_unstr does both in sequence, this routine should be called between the snapshot and the advection, or the advection kernel needs to be modified to call this internally.

Alternative approach (implemented here): For each boundary edge with inflow (mass_flux_e > 0), we don’t need to modify the scratch — instead we can post-process the advection to add the missing boundary contribution. But this is tricky with the current kernel.

Current implementation: mark boundary edges in state and let the advection kernel check bc_tr_ext directly. This requires modifying advect_tracer_one_cell to accept bc_tr_ext and check for boundary inflow.

For now, this routine is a placeholder that documents the interface. The actual BC application is integrated into the advection kernel.
